# AI 聊天正文长按菜单

- 需求与范围：纠正 #140 的长按即复制。用户消息、AI 正文及流式／中断正文长按时显示临时「复制」，点该项才写剪贴板；取消不写。平时不显示复制控件；短按链接仍打开，长按链接只出菜单。曲线卡片、附件及拖动不触发正文复制。
- 基线与分支：从 `develop`（`95b11163`）创建 `fix/ai-copy-context-menu`，PR 目标 `develop`。
- 改动：在共享聊天界面内弹出靠近长按位置的主题化菜单，使用应用字号。状态刷新保持当前长按目标；内容重建、会话或凭据更换、离页时收起旧菜单。复制可见正文，不含独立卡片、推理文字或状态标签。
- 验证：本地编译 Mock 仪器测试并检查受影响的字号、资源与隔离入口；在云端以现有 `ai_copy_checks` 入口注入真实窗口按下、抬起及菜单点击，覆盖长按不写、点击写入、取消、滚动和上述关键回归。不启用本地 AVD、实机或模型请求。
- 云端失败取证：两次运行在返回仪器断言前掉线。为该隔离入口保留仪器标准输出／错误、实时 Logcat 阶段标记和失败时的宿主机内存／内核信息；只将复制专项的物理屏幕从 1440×3120 @ 560 dpi 降至 720×1560 @ 280 dpi，保留约 411dp 逻辑宽度、原输入和断言；采样比较宿主 QEMU、控制端口与访客 ADB 的存活，不由分辨率对照推断 GPU 根因。
- 推送与合入：普通推送工作分支，经 `scripts/create-pr` 本地完整门禁创建 PR；等待该头提交的 `branch-policy`、`verify` 通过再合入，不直推。
