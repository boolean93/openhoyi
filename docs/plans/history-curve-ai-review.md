# 在历史萃取曲线旁评价当前这杯

- 来源：`develop@b74b13bc`。工作分支 `feature/history-curve-ai-review`，PR 目标 `develop`，常规推送和合入按[仓库 Git 工作流](../git-workflow.md)执行。
- 「AI 评价」属于单杯曲线详情，不放在历史列表顶栏。选中一杯后，入口在曲线名称这一行、详情三点菜单左侧；点「查看详情」打开全屏曲线后也有入口。以当前可见的曲线为准；切换记录或来源后不能评价上一条，没有可评价的曲线时不代发。窄屏查看详情时也能找到入口。
- 沿用 HOYI.AI 的手动完杯评价流程和现有同意机制。针对历史这杯提问，不改变当前聊天草稿、附件或后台自动评价设置。
- 验证：选中一条非最新记录，确认交给聊天的就是它；覆盖不可用记录与重复点击。用带采样的 Mock 历史在真实 Android 界面截图，查看按钮位置和曲线有无遮挡，不用真实 Key 发请求。
- 不改 BLE、秤控制、设备队列、签名、版本或用户数据格式，不发版。回退本次入口改动即可；保留聊天、历史和未确认设备记录。
