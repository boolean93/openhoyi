# 萃取评价不挤压主界面

- 范围：萃取页使用原有「工具」展示当杯的评价状态和入口；近期历史在该杯的「结束信息 / 个人记录」展示评价。评价不自动弹出，不占实时或历史图表的空间。不改 API 授权、请求内容、存储及导出行为。
- 基线：`develop` 的 `a0bb1245ab98a1606eeb0ac69ef460cca6e9dd85`；工作分支 `fix/shot-review-no-layout-shift`，PR 目标 `develop`。
- 改动：更新萃取双入口、历史详情和评价 UI 绑定；保留 Mock 测试入口及断言，并同步 README、功能表、实现说明和 Pages。
- 推送与合并：按 [Git 工作流](../git-workflow.md) 完成本地检查，使用 `scripts/create-pr` 创建草稿；精确 PR 提交的 `branch-policy`、`verify` 通过后再推进合并。不引入临时验证工作流。
- 验证：[隔离 Mock](https://github.com/boolean93/openhoyi/actions/runs/44701508897) 源提交 `3ef8178cbf4632301852ca2ce3a0e8fecc39fa4f`，320×484dp 浅色手机及 1138×618dp 深色平板，字号 1.0：五种评价状态下七处控件边界不变，并验证模拟关键告警与评价标记同时显示。平板通过控件层级读取了点开后的全文，详情截图未捕获到对话框；此轮未验证大字号及历史详情的截图。最终候选另跑本地及 PR 门禁。
- 协议与设备风险：不改协议、写入、取消、停止、安全门禁及重试。Mock 不连接咖啡机或真实 API，不代替实机验证。
- 发布与回退：本任务不手动发布、签名或安装；如需回退，走普通代码回退，保留评价记录和历史数据。
