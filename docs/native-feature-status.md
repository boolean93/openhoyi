# 原生版功能边界与下一步

此表以当前代码和旧版 `hoyi-project/docs/features.md` 为准；“已编码”不等于已在 Alpha 上实机验收。2026-09-24 用户已授权安装，原生 Alpha 已安装到平板并完成冷启动观察。2026-09-28 起用户短期不提供测试设备，以下未完成实机项目均延期，先推进离线开发与 Mock 验证。

| 功能 | 当前状态 | 继续推进所需证据 |
|---|---|---|
| HOYI 连接、认证、实时遥测 | Lab 已在固件 1.1.3 实测；Alpha 第二次 GATT 建链成功，认证写入后收到 0x83 设置与连续 0x40 待机遥测，进入 READY | Alpha 设置与机器屏幕对照、前后台及断线实测；首次 status 62 原因未定 |
| BOOKOO 连接、前台 10 分钟自动重连、独立去皮 | Lab 双连和记忆秤连接有短时证据；Alpha 冷启动后自动重连第 4 次进入 READY，持续收到秤通知；用户执行两次去皮均收到归零通知 | 断链后重连、完整前后台窗口、重复选择、秤屏对照与负重量实测 |
| 100 条工厂曲线、五个槽位、萃取启停 | 旧版编码器生成的两种秤模式报文逐字节匹配；Alpha 已用快捷槽位 5 启动 Hyper Ex，App 停止后用户确认机器停水；采集曲线 1、3 也有预去皮后手动停止与历史落盘证据，见 `docs/alpha-acceptance.md` | 按目标重量自动停止、采集曲线 2、其余工厂槽位、断线/未知结果与最终杯重对照仍待验收 |
| 机器设置、每日睡眠计划、立即睡眠、杯数重置 | 已编码旧版报文与回读确认，不自动重发未知结果；普通设置、整周睡眠计划和杯数重置有跨进程持久化未确认标记及同机回报门禁 | 每类设置至少一次新鲜回读和失败路径实测；立即睡眠、预热的跨进程保护尚需完成，高风险操作单独安排 |
| 实时曲线、本机历史、ZIP 导出 | 压力、机器水流、温度、秤重和秤报告流速已接入；旧采样 v1 可读；机器手动萃取的被动识别与历史已编码；历史同步落盘，近期孤立采样不会因索引缺失被立即删除；保留短杯/未知结果用于诊断（旧版只存≥15秒已结束杯） | 小屏图表、文件选择器、过程退出与部分曲线实测；手动拨杆真实帧验证识别阈值，秤流速物理单位校准 |
| 深浅色与原生 UI | 原生主页面共用昼夜资源，首页 Switch 保存偏好；云端 Mock 已截图核对 1600×1000 横屏、600×1000 竖屏的深浅色五个主页面，以及 360dp 宽浅色主页面和关键详情，见 `docs/ui/native-redesign.md` | 真机两种模式的对比度、系统栏、重建后的 BLE 连接仍待实测；Mock 不代表真实设备控制 |
| 旧版自定义曲线与曲线编辑 | 旧版完整曲线库导出、原生版只读导入与浏览已编码；用户已明确后置编辑，导入曲线不能启动 | 取得真实 `hy_chartLib` 导出并核对字段和顺序；开放控制前逐条验证有秤/无秤旧版报文与参数范围 |
| 旧版萃取历史迁移 | 显式 JSON 导入、独立只读列表和压力/机器水流图已编码；合成格式测试通过 | 取得旧包 `brew_history_v1` 的真实导出文件并核对条数、图线和重复导入；已修改旧版加入该键的导出菜单；仍需真实文件验证，原生包无法直接读旧包私有数据 |
| 其它秤型号 | 当前仅实装 BOOKOO；Acaia、Felicita 和 DiFluid 的部分旧版重量格式已提取为独立的离线只读候选解析器，不接入 BLE 扫描、去皮或萃取停止 | 对每个型号分别取得真实通知、初始化、去皮和负重量样本；DiFluid 旧版有多种模糊解析分支，不能仅凭合成帧开放控制；不复用 BOOKOO 写入 |
| 维护、排水、校准、恢复出厂、OTA | 不开放 | 需对应机型、固件和实机协议序列；对于缺少可靠回读的命令，需要单独设计中断与人工恢复流程 |

旧版“压力上限 10/12 bar”开关是 App 本地曲线编辑与图表范围偏好，不向机器写入；待曲线编辑阶段再实现。旧版水箱滤芯 `0x18` 有写入命令，但当前已验证的固件 1.1.3 未提供代码可确认的回读位，暂不开放写入。现阶段不把编译或日志里的 GATT success 当作机器执行成功。

完成当前用户自用范围的主要阻碍仍是 Alpha 实机验收。不能以秤 READY 推断咖啡机连接、写入控制或整个应用已完成验收。
