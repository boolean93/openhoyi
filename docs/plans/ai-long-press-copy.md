# AI 聊天长按复制

- 需求与范围：按用户纠正撤下复制按钮，只用长按复制用户及 AI 消息正文；气泡空白、流式和中断回答正文也可长按。曲线卡片与附件本身不复制，短按链接照常打开，纵向拖动不复制。
- 来源与目标：从 `develop`（`d70705a5`）新建 `fix/ai-long-press-copy`，PR 目标 `develop`。
- 改动：纯状态刷新不能移除正在接收长按的消息视图；真实内容、凭据或卡片动作状态变化仍更新。剪贴板逻辑沿用系统反馈和应用失败提示。
- 推送与合并：通过 `scripts/create-pr` 本地完整校验后普通推送工作分支，branch-policy、verify 通过后通过 PR 合入，不直推。
- 验证：编译 Mock 测试；手动隔离云端工作流注入真实 Android 窗口触摸并检查剪贴板。其中 DOWN 与 UP 之间进行纯状态刷新，确认刷新不取消长按。不使用本地 AVD 或实机。
- 协议、签名、升级及发布：无协议、队列、签名、版本、持久化变更；无手工发布、平板安装或机器操作。可通过 revert PR 回退，无需卸载或清除历史。
- 待验：云端代表场景不代替用户平板复验；不能据此确定原反馈的唯一原因。
