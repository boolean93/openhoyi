# 短时手动出水结束后保留实时计时

- 需求与范围：机器手动短时出水被确认结束后，实时曲线保留最后一个有效的机器计时，不改用横杠。不把短时出水计为一杯，不写历史或发送完成反馈。
- 来源与目标：从 `develop` 的 `e0cea92d` 建 `fix/short-extraction-elapsed`，通过 PR 合回 `develop`。
- 实现：将已确认结束与成杯资格分开。仅在被动检测器确认结束时冻结终态计时和对应的称重读数（未采到仍显示不可用），断连或服务停止不视为已结束。下一杯不继承上一杯时间。
- 验证与合入：覆盖短时出水确认结束、中断、下一杯与上一杯未知状态隔离；运行本地 PR 检查、普通推送并用 `./scripts/create-pr`，等待必需的 `branch-policy` 和 `verify` 通过再合入。本次不运行 AVD 或操作真机。
- 协议与设备风险：不改动协议、门禁、恢复记录所有权、停水命令或重试；不改变成杯门槛。
- 发布与回退：不手动发布或安装，不改包名、签名、版本和数据格式。需要回退时用 revert PR，不降级或清数据。

具体规则见 [Git 工作流](../git-workflow.md)。
