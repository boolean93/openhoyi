# 萃取曲线轴范围动态自适应 + 网格/刻度更细

- 需求与范围：
  - 用户平板实测反馈：萃取曲线横纵坐标「格子粒度不够细」，且坐标应「根据数值动态缩放」。
  - 用户已选方案（初版）：范围只扩不缩；历史详情按整杯自适应；网格按数值自适应（主刻度带数字 + 次网格线）。对比页复用同一适配。
  - 用户真机复验修正（观测驱动）：反馈「萃取曲线似乎只是改了单位密度，坐标并不会随着萃取进度变化」。根因：实时 X 轴被 `LiveChartGeometry.continuousTimeEnd = maxOf(previous, 30_000, projected)` 钉死在 0–30s；实时 Y 轴被配方种子（压力 0–10 等）预填满，整杯一开始就是最终范围。改为观测驱动、只扩不缩：X 从 5s 起按阶段边界扩展，Y 从小初始范围随观测值扩展；历史/对比不变。
  - 用户真机复验修正（平滑过渡）：阶段边界/nice 边界变化时轴瞬间跳变，只有曲线有 reveal 动画，观感「一跳一跳」。给实时轴（range low/high/step + timeStart/End）加约 380ms Decelerate 过渡动画；曲线 reveal 动画保留并行；历史/对比/嵌入历史保持静态。
  - 收尾（Astra note a + 体验）：实时 `end` 每次观测都变，若每次都用 380ms Decelerate 重启动画会产生 4Hz 速度脉动。改为按变化类型选过渡：仅时间轴变化（Y 范围/step 不变）时用 LinearInterpolator + 与观测间隔匹配的 200–300ms，连续匀速变化；Y 范围变化仍用 380ms Decelerate。
  - 用户 D 修正（纵轴按配方目标，一次到位）：D 方案实测压力轴首次从 0–2 直接到 0–15、9 bar 只占约 60% 高度且仍会扩 2–3 次。改为用曲线配方目标决定纵轴最终范围：第一次需要扩档时直接扩到目标范围（压力 9 bar → 0–10），曲线填满、通常一次到位；无可靠目标（手动/未知/流控无压力目标）回退 1.4/1.6 余量策略。
  - 用户 D 最终收紧（避免数学悬崖/曲线显平）：Astra 发现压力 seed ×1.1 在 ≥9.1 bar 时 expected 越过 10 → yAxis 步长 2.5→5 又变 0–15；温度 ±5 加 0.92 被抬到 85–105；水量 49.6 → 0–60。最终口径：压力 target=max(peak,10) 并向上取 2.5 bar nice 边界（9–10 bar 均 0–10，>10 如 10.5→12）；重量 5 步 nice；水量机器水量目标优先（75→80），无则目标重量×1.1+10（49.6→50）5 步 nice；温度目标±2 整数边界；流速 0–2（0.5 步 nice）。projection 对 expected 直接采用 nice 边界，不再经粗 yAxis；0.92 填充规则仅用于**无 expected**的通用扩档（温度继续豁免），有 expected 只在观测超过 expected.high 时按 overshoot 扩。Astra nit a（合并前补）：expected/overshoot 统一走 `ChartAxisScale.niceBoundary(rawHigh)`——在 nice step 中选使 `k=ceil(rawHigh/step)∈2..6` 且 `high=k*step` 最小（同高取更大 k）的组合，保证主刻度全为 nice 数字（35→40 step10、45→50、55→60、80→80 step20、10→10 step2、12.5→12.5 step2.5、17.5→20 step5）；空/非法返回 null 不崩。温度口径统一为“目标±2，实际按最小 5°C 跨度取整（如 90–95）”。已知：Mock 水量 75ml vs 实际 ~19ml 口径差（文档注明，真机 63–70ml 合理）；expected 迟到仅重置首扩 flag、不立即回头重扩（低频，后续按需再议）。expandAll 只扩有当前观测的轴；expected 迟到（profile 解析晚/选择变化）重置 yExpansionStarted 保证首扩同步机会。Mock 的机器水量（75ml）与模拟实际水量（~19ml）口径不同，Mock 水量轴会偏宽，真机 63–70ml 时合理。
  - 用户 D（纵轴降频）：横向缩放已满意，但多轴 Y 各自在不同时刻跳。改为保持观测驱动但降档：预扩阈值 85%、每 3 秒至多一次批量扩档、一次给足余量（新 high≈max(观测最大×1.4, 当前 high×1.6)）；同一次评估中所有达到阈值的轴一起扩（同一 380ms 动画事件），未达阈值的保持不动；观测超出当前 high（会裁切）时立即扩、不受节流。历史/对比不变。
  - 用户最终澄清（连续缩放，推翻滚动与阶段扩轴）：实时时间轴始终 `start=0`、`end=max(10_000, observedEnd)`。前 10 秒固定 0–10s（曲线从左往右画）；超过 10 秒后 end 连续跟随观测变大（0–12、0–15……），整杯曲线始终完整显示并被平滑横向压缩，最新点仍落在右边界（end=当前时长）。视觉是「连续缩放」，不是滚动换档、也不是 5→10→15 阶段扩轴。`timeStartMs` 字段保留但 live 恒为 0；结束/空闲时 end 自然等于整杯时长（无需额外 follow 状态）；历史/对比仍 start=0、整杯取整自适应；空闲无观测预览仍可显示完整参考杯。
  - 真机复验追加根因（参考曲线预撑）：实时页会自动加载同曲线上一杯作参考曲线（`ExtractionFragment.loadReference`），而 `FourMetricChartProjection.build` 把 reference 一并计入 `values` 与 `observedEnd`，于是即使没有配方预填，参考杯的时长/峰值仍会把实时轴预先定长定高。修正：当前杯已有观测时，实时 X/Y 轴只由当前杯驱动；参考曲线照常绘制，超出当前轴范围的部分由 canvas clip 裁剪、随进度展开逐步露出；当前杯无观测（空闲预览）时仍由参考杯决定轴与时长；历史/对比仍包含参考、按整杯自适应。
  - 范围：实时萃取页、历史详情（共用 `ProductHistoryChartRenderer` / `FourMetricChartProjection`）、对比页共用适配。纯显示层，不改协议帧、出站命令、采样/存储/历史数据。

- 改动文件与步骤：
  - 新增 `mobile/src/main/kotlin/io/openhoyi/mobile/ChartAxisScale.kt`（纯逻辑）：
    - `niceStep(low, high, targetDivisions≈5)`：从 {1, 2, 2.5, 5, 10}×10^k 取步长；`yAxis` 向外取整，保证 `range.low/high` 恰为首末主刻度、包含全部观测值、2–6 个主分隔；同值数据给有限区间；非法输入抛 `IllegalArgumentException`。
    - `majorTicks` / `minorTicks`（半步细网格）。
    - 时间轴 `timeAxis`：nice 秒步长（1/2/5/10/15/20/30/60s，超长按整分钟）；历史/对比把 timeEnd 向上取整到主步长；实时 end 连续（不取整/不分阶段）。渲染 X 映射用 `(ms-start)/(end-start)`（实时 start 恒 0），刻度 0…end，末端标签仍为 end 秒数 + " s"。
  - `FourMetricChartProjection.kt`：
    - `FourMetricChartData` 末尾新增 `timeStartMs: Long = 0`（live 恒 0、历史/对比 0）；实时 `end=max(10_000, observedEnd)`、`start=0`；空闲预览（无 current、有 reference）`start=0, end=max(10_000, referenceEnd)`；历史/对比现有 timeEnd 取整逻辑不变。
    - `ChartMetric` 由固定 floor/ceiling/step 改为每指标 `minSpan`（压力 4 bar、水量/重量 10、温度 5 °C、流速 2）、小的实时初始范围（压力 0–2、水量 0–10、重量 0–10、温度 90–95、流速 0–1）与历史空数据回退（沿用 0–10/0–40/0–40/88–98/0–4），并标记低频物理量锚 0、温度不锚 0。
    - `MetricChartSeries` 暴露 `step`；`build` 不再接收配方种子。
    - 实时（Y 轴迟滞 + 配方目标）：`old==null` 用初始小范围（首次观测已超出则立即扩）；`old!=null` 时仅当 `allowLiveExpansion` 且观测达到当前 range 的 85%（温度低端同理）、或观测超出当前范围（must，立即不受节流）才扩；否则保持 old range/step（目标不变→无动画无抖动）。
    - 实时（配方目标扩档）：`build` 增加 `expectedLiveRanges`、`previousSteps`、`expandAllLiveAxes`。有 expected 时直接采用 `niceBoundary` 边界范围（step 也取自该组合，主刻度全 nice，不再经 targetDivisions=4 的 yAxis 造成 10→15 悬崖）；观测超过 expected.high 才按 overshoot 扩：对 `max(obs×1.2, expectedHigh×1.2)` 再走 `niceBoundary`，温度用整数边界并按 minSpan 保底、豁免 0.92。`observed/newHigh ≤ 0.92` 只用于无 expected 的通用扩档。`previousSteps` 让 held 帧原样返回旧 step，避免 range 不变而 step 变化触发多余 380ms 重排。`expandAllLiveAxes` 用于新杯首次扩档：所有**有当前观测**且带 expected 的 live 轴在同一 build/同一次动画一起扩，无 expected 或无观测的轴除非 must 否则不动。
    - 当前杯已有观测时参考曲线的值/时长不参与实时轴范围（仅照常绘制、超出部分裁剪），空闲预览才让参考曲线决定轴与时长。历史：整杯 current+reference min/max + 最小跨度，不受节流/配方目标影响；`previousRanges` 非法仍拒绝。
    - 历史/对比 `timeEndMs` 向上取整到时间主步长；实时保持观测末端。
  - 新增 `ChartAxisSeed.kt`（纯逻辑，输出的 high 均由 `niceBoundary` 生成）：压力 0..niceBoundary(max(分段峰值 bar,10))（9–10 bar→0–10、10.5→12）、重量 0..niceBoundary(max(目标重量 g×1.05,10))、水量 **机器水量目标优先**（×1.05 后 niceBoundary，如 75→80、108→120），无机器目标回退 目标重量×1.1+10（niceBoundary，49.6→50），最小 20；温度 目标±2 整数（实际按最小 5°C 跨度取整，如 90–95）；流速 0..niceBoundary(max(流量目标×1.5,2))。手动/未知/流控无压力目标不臆造，对应指标缺省时回退投影余量策略；非法/非正输入返回 null 时跳过该指标。
  - `LiveChartGeometry.kt`：删除阶段边界 `stagedTimeEnd`/`liveTimeEnd`（时间窗口改由投影提供），仅保留 reveal/曲线插值工具。
