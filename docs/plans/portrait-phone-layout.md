1. 首页保留最近曲线复用、五个预设和设备操作，改为中性底色配绿色、单张机器图、双锅炉温度进度仪表及下方压力。快捷缩略图复用曲线库的压力／流量语义和配色，不生成示意采样。
2. 实时页强化画布，末端 caption 显示真实最新采样和单位，位置随原曲线插值和动态量程移动；处理碰撞、边缘、缺测、暂停与新轨迹，不对读数制造插值。流速沿用实际秤推导的 g/s，不替换为配方控制 mL/s。
3. 竖屏六入口底部导航，横屏保留原侧栏规则；按 Configuration 方向判断，避免键盘改变窗口高度时切换导航。
4. 详情、投粉、导入预览、分享和复盘使用自然正文滚动与独立主要操作，保留原点击和业务门禁。完整名称、数字及单位按真实宽度排布，修复局部小窗、截断、拆单位和大字号拥挤；库存流水竖屏分层显示数量、批次和原因。
5. 竖屏适度调整标题和大数值层级，保留正文、系统字体倍率、触控尺寸和横屏字号。
