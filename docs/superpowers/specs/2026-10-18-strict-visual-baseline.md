## 3. 可审阅的设计补充值

### 3.1 字体、字号、字重和行高

选择 `Noto Sans SC 2.004-H2` 原始变量字体作为中文可复现候选。文件 SHA256 为 `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`，来源与许可见 [字体候选记录](../../evidence/task-first-font-candidate.json)。选择理由是中文和数字可统一、字重可复现、已有来源与许可核验；**不是因为实现已使用它便视为稿件原字体**。非中文沿用原 fallback，不借此改变其他语言字体。

| 角色 | 字号 | 字重 | 候选行高 | 用法 |
|---|---:|---:|---:|---|
| 正文/表单输入 | 16sp | 400 | 24sp | 名称、正文、输入；操作标签使用 500 |
| 辅助/单位/图表轴标 | 14sp | 400 | 22sp | 次说明、普通数值单位、轴标；不能把主字段降为辅助 |
| 分区标题 | 20sp | 500 | 30sp | 本杯准备、阶段目标、最近流水等 |
| 页面/详情主标题 | 24sp | 500 | 36sp | 页面标题和选中项主名称 |
| 配方数字 | 24sp | 700 | 36sp | 温度、目标液重等；单位独立为 14sp/400 |
| 普通大值 | 40sp | 700 | 60sp | 库存重量、秤工具重量等 |
| 萃取聚焦主值 | 48sp | 700 | 72sp | 时间与有效重量/注水主值 |
| 萃取聚焦单位 | 22sp | 400 | 34sp | 主值旁的秒、g、ml；和数字逐 span 测量 |

以上行高是主动提出的设计值，取整后给中文约 1.5 倍字号的行距，不声称从生成图精确读出。候选须先实测中文字形、数字和单位基线；不得因设置行高裁切字形。系统字号通过 Android 实际换算；不能在大字号下锁死像素行高或简单乘 1.3 猜测实际字号。若字体实测需要更高行盒，由 Astra 根据样张修改草案并记录原因，再冻结，不能由 Sol 静默缩字。

普通控件 `includeFontPadding=false`、不伪粗体、默认字距 0；原生特殊控件的基线差异单列。主读数使用等宽数字候选；实际字体是否提供对应特性须测量。不得为了截图接近而删小数、改单位精度、隐藏负值或把缺失改为 0。Canvas 轴字也纳入字号/字重/基线取证，不能只检查 TextView。

### 3.2 间距和几何

| 角色 | 候选值与约束 |
|---|---|
| 相关项间距 | 8dp |
| 组间距、普通卡片内边距 | 16dp |
| 主辅栏之间 | 24dp；分隔线是否居中由逐页锚点标注 |
| 页面内容边距 | 16dp；不含系统 Insets 和导航轨 |
| 容器圆角、控件圆角 | 16dp、12dp；选中列表项按原稿标注，不把整行改为大卡 |
| 导航轨 | 标准横屏候选 80dp，属于原 72–80dp 范围内的明确选择；大字号按既有回退保证入口 |
| 细分隔/描边 | 1dp，记录实际栅格化宽度；不假定 1dp 等于 1px |
| 操作行 | 两控件外框垂直居中、共享行外间距；行上间距 8dp；禁止单个按钮附加非对称 6dp 偏移 |
| 触控和固定操作 | 至少 48dp，主要按钮基础 56dp；`wrap_content` 允许字号和换行增长，不能靠固定高度裁字 |

栏宽、图表绘图区、表单限宽、标题与操作区位置必须逐页标注，不能凭通用间距表认为全部一致。以原稿的导航右边界、标题基线、内容起点、栏分隔、图表绘图区和操作区为锚点，保存原 PNG 像素坐标和拟映射的目标 dp。画布和系统可用区比例不一致时，在原生样张中做明确的自适应设计取舍，并记录被影响锚点；禁止非等比拉伸原稿后计算“相似度”。

## 4. 四项独立硬门禁

每页、每个必验状态分别记录以下四项。状态只有 `PASS`、`FAIL`、`BASELINE_PENDING`、`EVIDENCE_PENDING`；最后两者均不算通过。不能用一个总视觉分数抵消失败项。

| 门禁 | 必查内容 | 通过证据 |
|---|---|---|
| G1 间距/构图 | 内容区、栏宽、边距、内边距、组间距、行盒、基线、圆角、描边宽、图/操作区位置 | 原稿锚点标注、冻结布局参数、运行几何、同状态完整 PNG；数值与布局实现的确定性换算相符且人工对照通过 |
| G2 字体 | 字体文件身份/SHA、实际字重、伪粗体、字距、数字特性、中文 fallback、单位样式 | 字体文件记录、真实 Typeface/字形测量、逐 span 报告；不能只输出一个全局字体名称 |
| G3 字号/行高 | 每角色 sp、实际 px、行高、基线、font padding、每 span 的尺寸、Canvas 文字边界 | 同运行配置的测量值与冻结角色映射；所有文字不裁切、单位层级符合样张，大字号另验 |
| G4 背景/状态色 | 页底、内容面、导航、主辅文字、主/次/危险/禁用操作、边框、选中态、图表色、alpha 叠层 | 资源解析后的实际 ARGB、Drawable/Canvas Paint、纯色内区采样、完整 PNG；冻结状态表与人工对照均通过 |

功能可用、布局无裁切、四项视觉门禁、硬件验收分别记账。一个页面只有全部必验状态的四项均通过，且原功能/安全要求通过，才算视觉完成。Mock 中的同状态截图可用于 UI 验收，但不能变成真实设备控制证据。

### 同状态、同视口取证契约

每份证据包含：精确源码 SHA/是否 dirty、APK SHA、CI run/job、测试入口、fixture id 与输入摘要、locale、theme、display size/density、fontScale、API/模拟器镜像、窗口 px/dp、系统 Insets、IME 可见及 Insets、应用内容边界、截图帧已布局条件和证据文件 SHA。

标准态以用户平板配置、中文、浅色、fontScale1.0 为首轮。原稿数值只是示例；确定 fixture 应按相同业务语义与相近长度建立，并使用真实投影。在不能保持相同数值的地方标明不同，不比较曲线轨迹的逐像素形状；不得倒造数据或控制状态。UUID 长名压力夹具和正常中文样张分别保存，不能以随机长名截图替代正常字体审查。

fontScale1.3、该固定系统镜像可设置的最大字号（保存实际值）、短高和 IME 各用独立 profile。浅色和深色不能混比；旧 `1600×1000 / density200` 结果不能覆盖用户 profile。组件测量 PNG 必须标 `componentOnly=true`，不能用于整页通过。系统栏仅按记录裁出用于对照的应用区域；原始整窗图一直保留，不用裁图隐藏溢出。

### 精确比较与抗锯齿

原 ImageGen 稿承担设计构图、层级、风格审查；通过审查后的确定性原生样张承担精确回归。二者不能互相替代，也不能把未经设计审查的“当前截图”直接建为黄金图。

先比较 token、实际 Paint/Typeface 和几何；同 profile 下要求确定性输出一致。dp→px 的整数取整、分栏余数分配和 Android 字号换算必须显式记录并按相同算法预测，不能加随意的 ±1px、百分比差异率或模糊阈值。

若不同系统渲染器仅在字形/曲线边缘出现覆盖率差异，须先证实字形轮廓、字重、文本位置、基线、区域内部颜色相同，再保存差异区域并单独人工判定为栅格化差异。不能先对整图模糊、扩大边缘遮罩或降低清晰度以取得通过。换行、真实笔画粗细、基线位移、色块内部颜色、边框和区域边界改变均是真实差异。标准 CI 固定相同镜像时仍应保留原始像素差异，不以“抗锯齿”笼统放行。

### P0：只增加可验证的取证，先不全局改视觉

扩展现有 `TaskTypographyEvidence`，复用现有原生截图与fixture入口，不另建并行截图体系。当前实现已采集多数TextView尺寸/字重/span和布局；需补实际色值、真实字体身份/回退、基线/字距/数字特性、Drawable叠层/边框/状态及Canvas文字。稳定的语义标识优先于层级路径；保留原path便于追踪。不能把全局字符串“Noto”视为每个节点的字体证明。
