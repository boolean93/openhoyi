# 固件版本与协议支持状态

首页咖啡机卡片新增只读版本状态，补齐旧版版本查看的日常入口。本次不新增更新、探测或控制命令。

`DeviceSession.observedFirmware` 从通过当前连接认证阶段后接收的有效 `0x83` 设置字段构造不可变 `CoffeeFirmware`。未认证帧、错端点、旧连接帧不能提供身份；断开、失败或换设备清除原设置，版本随之清空。Hub 和 Mobile 只透传版本身份，不把未知固件设置送入正常控制快照。

| 状态 | 首页展示 |
|---|---|
| READY、已进入控制档案的 1.1.3（实机验收）与 1.1.4（协议证据支持放开，待实机启停/设置验收） | 固件 1.1.3 / 1.1.4 · 已验证协议 |
| UNSUPPORTED，例如 1.1.5 | 固件 1.1.5 · 暂不支持新版固件（状态行：暂不支持新版固件 · 控制已禁用） |
| 认证后未收到兼容设置帧、同步超时 | 固件版本读取超时 · 可能是暂不支持的新版固件（状态行：协议初始化超时） |
| 未认证、重连、断开、失败或未读取版本 | 固件版本：等待连接后读取 |
| Mock 已就绪 | 模拟固件 1.1.3 · 无蓝牙控制 |

“已验证协议”表示匹配当前已有报文证明和固件许可；不表示所有功能已验收，也不保证机器执行结果。1.1.4 目前只有静态协议证据，启停与设置写入仍需真实机器验收，不得据此宣称已验证。显示版本不产生新控制许可；不在控制档案内的固件仍不接受启动、停止、设置、立即睡眠、预热或杯数重置，连接保持但不自动重连。

失败分类只用于显示，不参与任何控制门禁：GATT 建链失败显示“连接失败”；认证帧写入阶段失败显示“认证未完成，请重试”（传输失败不能证明密码被拒）；认证后 10 秒内未收到兼容设置帧或初始化未完成显示“协议初始化超时”。自动重连策略不变。

离线会话测试检查认证前版本为空、1.1.3/1.1.4 版本值、断开与换设备清除、旧连接通知被忽略、未验证固件（1.1.5）控制请求没有新增传输调用，以及四类失败分类与重连清空。UI 单测检查就绪、暂不支持、超时、断开/连接中与 Mock 文案；真实版本显示和小屏布局仍待设备验收，云端 Mock 采集仅验证模拟界面。
