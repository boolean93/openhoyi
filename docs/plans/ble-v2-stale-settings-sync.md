# BLE V2：已认证但设置回读过期
来源 `e0004018`；隔离本地分支 `fix/ble-v2-manual-settings-sync-local`。本轮不推送、不建 PR、不打包安装。若进入交付，按项目工作流对当前 develop 重新审查。旧版/签名/正式包边界不变。

- Home 两个锅炉共用一个回读入口，机器设置页也可操作。过期值仍不能写入；用户明确点「同步机器设置（会校时）」才触发有界 0x01，不把它说成纯读。同步不执行或保留锅炉操作；等收到当前连接的新设置后，用户另点目标操作。状态区区分等待、收到和未确认；既有冷却窗口、防重发、禁自动重连不变。
- 0x83 同时携带多个设置，并非多条独立回执。设置帧必须源于当前认证连接，且原生接收时间在本次实际交给传输以后；旧回调不会因主线程晚处理而重新计时。确认需要 0x01 GATT 成功和合格的新 0x83 两者。认证帧不解除历史未决操作，活跃萃取、刚收到的故障、休眠、预热、待处理控制和所有原有持久安全限制继续生效。
- 验收：原生 DeviceSession 假 GATT 逐项检查成功、超时、旧帧、换代、只 ACK、零自动锅炉动作；实际 Home / 设置页 Android 显示与实机未运行。无破坏性迁移：可撤销此本地提交，不删任何既有待核对数据。
