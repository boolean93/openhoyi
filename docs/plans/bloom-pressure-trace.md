- 基线与交付：从 `origin/develop`（`b74b13bc`）建立 `fix/bloom-pressure-trace`。按[Git 工作流](../git-workflow.md)，如推送则普通推送该分支，用 `./scripts/create-pr` 向 `develop` 提 PR，等待必需检查，不直推主干。
- 依据：萃取帧 `0x80` 的压力字段与闷蒸状态位相互独立，参见[闷蒸位核实](studio-auto-preheat.md#新回读字段核实)。用仓库的[实机回放](../../mobile/src/androidTest/assets/live-curve-real-replay.json)验证原始值、零压和真实时间缺口；对照历史与实时投影。
- 协议与回退：只改读数展示，不改采集、存储、机器指令、签名或版本。没有闷蒸标记的旧记录不臆测；不回填历史。撤回展示改动即可回退，无需迁移或清数据。本任务不安装、不发版。
