# 应用页面背景

- 需求与范围：在外观设置中独立选择默认纯色、两款低对比内置背景或本地图。支持预览、遮罩、取消、应用与恢复默认；不影响深浅、配色、字号和语言。
- 来源分支/基线：在等待主题 PR 合入期间基于包含主题候选及 #136 的 `278644cf` 开发；创建 PR 前同步最新 `develop`，确保最终差异仅含背景功能。
- 工作分支：`feature/page-backgrounds`。PR 目标：`develop`。
- 实现：私有背景配置和文件事务、系统选图、可恢复草稿、显式页面背景层及不透明内容保护。导入限制 20 MiB，归向并重编码，输出最长边 2048 像素且最多 4 MP，不保存 URI、原文件名及原元数据。
- 推送与合并：仅正常推送工作分支，使用 `./scripts/create-pr`，同一 PR 头部 `branch-policy` 和 `verify` 通过后合并。Mock 窗口证据在隔离云端采集，不增加常规 PR 门禁。
- 验证：文件替换和失败回退、取消与过期异步结果、配置重建与返回栈刷新；比较默认像素，检查明暗极端照片下浅深色内容、图表及导航不透底。实际云端验收与编译分开记录；背景启用时首页锅炉/快捷栏、设置节和曲库浏览视图按内容组保护，不拆成逐标签色块。
- 协议及设备：不修改连接、门禁、编解码、启停或未知记录；背景应用原地更新，不重建 Activity。作为新页面正常离开预热页时，既有取消规则不变。
- 发布和回退：不发版、不打标签、不改变签名、版本和升级边界，不安装或操作实机。回退仅回退代码，旧版忽略独立背景偏好及包内背景副本；不清用户原图或业务数据。
- 未完成：云端窗口证据、完整本地门禁及 PR CI 待实施完成后运行。

隔离云端手动验收同一 Mock APK 内的主题和背景：
`gh workflow run mock-lifecycle.yml --ref feature/page-backgrounds -f page_background_checks=true`。

具体规则以 [Git工作流](../git-workflow.md) 为准。
