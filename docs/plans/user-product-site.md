## 手机优先验收

1. 普通用户看首屏能说清这是用安卓手机连接HOYI咖啡机的App，而非咖啡品牌或开发工具；知道是测试版。
2. 390/320手机，正文直接能读、按钮易按；支持设备、测试限制、真实APK入口、开始使用步骤都在站内，不送用户去README寻找答案。
3. “下载测试版”先到知情下载区；真正APK链接对应已公开资产。测试风险与截图/包差异同卡常显、不在隐藏的免责弹窗；无自动下载、自动安装或用户设备操作。
4. 功能说明短而具体，手机图片能讲清对应功能，而不是把整张平板图缩成小字；查看原图是补充而不是理解页面的必经步骤。图片不假称手机布局。
5. 源码构建退出主页面；兼容、下载与入门路径不用开发术语。不通过夸大自动停水/无人值守/稳定性让页面显得易用。
6. 代表性手机和桌面浏览器实际点击检查；保留键盘、禁JS、减少动画与原图关闭回焦。精简静态回归覆盖下载URL/版本/限制、素材哈希/尺寸/本地资产/许可，无新增无关原生矩阵。
