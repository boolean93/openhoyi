# Outbound write boundary

授权范围：持续开发原生协议保护；不开放新命令，不操作真机。

选择在DeviceSession与GattDriver之间增加纯Kotlin GuardedGattDriver。比只在UI拒绝更靠近实际发送；比改造Android蓝牙API更容易离线证明拒绝时没有调用传输。原始AndroidGattDriver仍是通用底层，保护范围是所有DeviceSession实际使用路径，不声称拦截其它代码私自新建底层驱动。

OutboundWritePolicy依据设备角色、固定GATT端点、已有命令长度/字段/范围/校验识别合法编码。BOOKOO只允许当前四初始化帧与去皮；咖啡机仅允许认证、启动/停止、已有设置、睡眠两片及立即睡眠、杯数重置、温度等待。未知opcode/未知端点/角色错配/畸形帧拒绝。`0x11`（十进制17）只接受现有等待温度格式；`0x17`（十进制23）的恢复出厂/忽略告警冲突命令一律拒绝。

格式合法不等于有权执行：曲线真实帧授权、固件、认证、连接代次、状态、新鲜度、持久恢复记录等仍由现有逻辑决定。此边界不新增重试、不改超时、不取消紧急停止、不修改传入字节。认证错误不包含密码或字节转储。

文件：device-session的OutboundWritePolicy.kt、GuardedGattDriver.kt与测试；DeviceSession.kt只替换queue使用的驱动。

## 验证记录

缺GuardedGattDriver时四项测试编译失败；实现后四项通过、原会话92场景通过。随后扩展为8项JUnit，覆盖全部已有设置范围（含待机配对）、等待温度、三条采集启动、两片睡眠、认证、立即睡眠、杯数重置、停止六槽位、BOOKOO四初始化及去皮；未知opcode、截短/追加/校验损坏、非法设置、角色/端点错误被拒绝。假驱动的调用记录证明拒绝时没有进入传输；接受时对象身份不变，generation/token/withResponse保留，传输拒绝只调用一次。

最终完整离线任务成功：protocol-core 39,823检查/32,856通知回放；会话92场景；device-session JUnit69项无失败；Alpha/Mock各115项、114通过、1项缺真实导出跳过；Lab/Alpha/Mock三APK构建成功。日志/private/tmp/hoyi-outbound-full.log。新生产类不依赖Android，DeviceSession现有文件只替换queue驱动构造一处。

格式策略对启动保持原编码器的线格式范围，不自行认定全范围启动参数安全；真实启动许可仍是现有采集帧集合及上下文门禁。认证重新编码检查不会记录密码；BOOKOO逐字节匹配已有帧，不为其它秤放行命令。没有真机验证。
