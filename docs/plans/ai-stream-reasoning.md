# AI 流式思考隔离候选

- 来源：AI 页面第一阶段本地候选副本；目标：后续 AI 功能分支，当前不是 Git 工作树，不创建 PR。
- 分工：实现 SSE 安全传输与离线测试；协调者独立复核协议与体验，UI 由独立实现者接入。
- 体验：真实非空 reasoning delta 才显示思考；等待注释不冒充思考；推理为默认折叠纯文本，正文实时预览但成功前不提交。
- 协议：Koog 继续控制工具策略；SSE 完整聚合后进入既有 POST 历史与响应门禁。推理完整保留内存协议历史，显示限额独立；不记录原始推理日志。拒绝、长度、错误、取消和密钥变更维持原有安全边界。有效终态与 [DONE] 缺一即失败。
- 限额：组装后的响应仍为原 128KiB；逐事件/行有界，wire 独立有限预算（响应预算的 128 倍），防止 token envelope 过早耗尽正文预算。读取 30 秒、连接 15 秒、agent 总计 60 秒不延长；长思考仍可能超时。
- 验证：离线 SSE framing、UTF-8、工具聚合、usage、拒绝、终止、限额与取消；真实 Koog→协议适配→mock SSE→本地只读工具→后续请求链路；现有协议/重试/会话回归。以实际测试日志为准。
- 不发版、不安装、不操作设备、不调用付费 API；包名、签名、versionCode 与升级流程未触及。
- 回退：撤回本次精确源码补丁，恢复原非流式 POST；不变更持久会话数据格式。
