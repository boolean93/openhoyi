# 修正首页照片被整块底板遮挡

- 需求与范围：按用户截图修复首页。保留圆形表盘自身底面，让照片在圆盘外、两列之间和分组之间贯通。压力及锅炉开关每列共用一个小圆角底，快捷标题及图例单独共用一条窄底。已有底面的模式按钮、短窗锅炉卡及曲线卡不改布局。
- 来源分支/基线：`develop` `95b11163`。工作分支：`fix/dashboard-background`。PR 目标：`develop`。
- 实现：只在首页标记新增圆角保护区域；未设置背景时，不变更控件、颜色、排版、触控和事件。测试修正旧的“两表共用整块矩形”验收。
- 推送与合并：本地相关验证及 `./scripts/create-pr` 门禁后正常推送；同一提交的 `branch-policy`、`verify` 通过，另取隔离云端 Mock 首页浅深实际窗口证据，独审后合入。

- 协议与设备：不修改机器控制、连接、写入、停止、预热或历史，不连真实设备。
- 发布与回退：本 PR 不打标签、不发正式版；混淆 Mock 由协调线程在核验源码、签名、版本和升级边界后交付。必要时回退此代码，不清背景偏好、照片或业务数据。
- 验证进度：本地 Mock 仪器测试代码定向编译及首页布局、背景单测通过；云端实际窗口待验证。
