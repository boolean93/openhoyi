# 待机温度设置

旧版 `standby.vue` 的温度滑块范围为 `0–100 °C`。保存时调用 `setStandby(时间档位, 温度)`，只发送一条 `14 02 <档位> <温度> 00`。档位 `0–4` 对应机器回读的 `0/15/30/60/120` 分钟。温度和时间共享这条命令，不能只改变温度而省略当前档位。

原生设置页只允许输入 `0–100 °C`。发送前必须有已验证固件、当前连接的 `0x83` 设置帧和新鲜唤醒待机遥测；时间档位必须是旧版已知五档。确认前再次比较机器当前时间档位与用户选择时的值。写入成功只表示 BLE 传输完成，新一条 `0x83` 设置帧同时回报目标温度与保留的时间档位，才显示已确认；失败和未回读继续按现有设置事务显示。

`generate_machine_setting_oracle.py` 对五档 × 101 个温度生成505条旧版 `setStandby` 对照帧；连同其它设置共587条。当前尚未安装 Alpha，也没有实机修改待机温度的证据。
