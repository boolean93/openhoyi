# 官方 HOYI 图片提案：拒绝重复 JSON 字段
- 需求与范围：普通图片对话识别官方曲线时，转录重复成员有歧义。以原始 JSON 对象为作用域拒绝重复（包括相同值及转义同名），不改变一般创建/替换/复制分流。
- 来源／目标：develop `0d45c4da49693c46ed8e82997d279e51893931b3`；分支 `fix/official-photo-json-keys`，PR 目标 develop，按 [Git 工作流](../git-workflow.md) 完整检查与正常 PR。
- 实现：沿用 Kotlinx JSON 的语法解析；转换前对其原始文本遍历对象键，按解码后名称判断是否重复，避免 AST 最后值覆盖。包含外层、转录全局字段及数组中的每段对象；同名出现在不同阶段或名称文本不算重复。若外层重复 operation 掩盖明确的转录，仍拒绝。不变更图片来源、数字/单位、范围、显式保存规则。
- 验证计划：直接回归覆盖冲突、同值、转义同名、重复外层与夹带、跨阶段同名及通用创建透传；复跑离线假 SDK、附件、schema3 与显式保存，复核日晒与合成 HS/LS 的现有参数。不能验证真实模型 OCR、图片意图路由或真实设备；不调用外部服务。
- 协议、发布、回退：不改协议、单位、队列、设备控制/门禁、数据格式、签名、版本、安装或发布。回退该校验即可，不清会话、配方、附件和数据。
- 本地结果：Kotlin 2.3.10 缓存编译与 JUnitCore 精确 mapper/工具调用等 51 项全通过（35 项原有＋4 项直接回归＋12 项独立离线用例）；`git diff --check` 通过。未运行完整 Gradle、Android 设备或在线模型。
