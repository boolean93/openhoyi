# Manual observations on the real extraction route

This slice replaces the separate manual chart popup on the ordinary MainActivity shell. After two credible valve-open observations, the foreground, focused shell reveals its existing ExtractionFragment, with the prior tab/retained Fragment available via Back. The history qualification threshold remains independent. There is no automatic recipe selection, profile execution, boiler preparation/cancel, permission prompt, or App ownership of the shot. Existing extraction does not get replaced. Observe-only has no Start/Stop; follow the machine lever guidance. The chart keeps its provisional observation identity while the sample series gains its durable history identity.

A short discarded flush returns only an untouched automatic entry to its original tab. Back or navigation consumes the presentation once and cannot reopen the same cup. A valid completed or interrupted observation remains visible with the truthful terminal outcome. Do not navigate over a focused modal or a separate Activity; if the same observation is still active on return to MainActivity it can open then. The old fragment class is a restore-only compatibility shim and cannot mount a dialog.

Remaining breadth: older standalone comparison/editor screens previously requested automatic live presentation anywhere. Do not use CLEAR_TOP or launch a custom clone. The follow-on can factor MainActivity's actual extraction host contract (profile resolution/read-only presentation, navigation actions, service binding, transient dialogs) so a standard in-task Activity can host the same ExtractionFragment without altering the underlying Activity or draft. Permit only the single focused host to claim before navigating. A full-screen shared host must distinguish passive entry, refuse recipe actions and permissions until user leaves observe-only, deduplicate the exact observation, and preserve Back/editor state. Verify standalone visible handoff, cancel/finish before launch, rotation/process restart and editor restoration before calling that broader scope complete.
