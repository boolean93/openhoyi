# 设置、短列表与曲库的照片背景

- 从 `develop@3ced959f` 建 `fix/photo-ui-surfaces`，目标为 `develop`。设置页的标题、分类和章节外层，以及曲库的筛选栏使用主题色半透明底。选中项、输入和机器控制保留清楚的衬底。
- 历史和豆仓的短列表仅在有记录的位置画底，保留完整滚动窗口。纯色和内置渐变沿用原有样式。
- 用同一平板、同一张带明暗分区的测试图和相同数据对照修改前后，查看深浅主题和纯色回退。隔离 Mock 包用于视觉取证，避免替换平板上另行测试的 BLE 构建。对应更新照片截图测试的取样位置。
- 按[Git 工作流](../git-workflow.md)验证本任务的改动，共享时通过 `./scripts/create-pr` 向 `develop` 提交。此改动仅调整应用绘制，未涉及机器协议、签名、升级及发布。回退本次提交即可恢复原有绘制。
