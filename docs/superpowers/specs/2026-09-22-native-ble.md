# Native BLE 第一阶段规格

用户已授权边开发边多轮检查。交付三个独立模块，而非替换当前 UI。优先设备为 HOYI 固件1.1.3 和已采集 BOOKOO；历史协议资料不等于通用兼容承诺。

边界：transport只传字节和GATT事件；codec纯编码/解码；session负责连接就绪与初始化；extraction策略负责启动、延迟去皮、新鲜重量与停止去重。设备控制入口只能接受结构化命令，不暴露不受检查的任意opcode给业务。

要求：每连接一个在途操作，旧generation回调隔离，超时使连接失效防回调串位；结果区分排队/已提交/传输完成/结果未知。无设备回读时不宣称已执行。未知帧不覆盖有效状态。停止优先于未发送普通写，不能抢占已提交GATT。断线不重放旧命令。所有状态使用单调时间判断时效。设备会话不绑定页面。

验证：真实样本3条曲线编码；机器0x83/40/80与BOOKOO通知；异常长度校验/负值/单位；初始化间隔；两设备不串线；启动不重试、重量停止不重复、陈旧重量不触发正常目标达成。后台Service宿主/UI、其他秤、OTA及管理命令列为明确未交付项，不用空实现冒充支持。
