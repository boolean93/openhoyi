# 产品官网：极简白改版

遵循 [Git 工作流](../git-workflow.md) 与 [任务模板](task-template.md)。本规划取代此前“用户优先版”的视觉目标，不取代其受众与事实约束。

## 需求与用户反馈

- 用户反馈上一版审美与体验不足，明确选择方向：**极简白、苹果风**，截图当主角；测试版风险提示**尽量淡化，只保留最关键几条**。
- 受众仍是普通用户：先讲清这是安卓 App、能做什么、设备是否支持、怎么下载与开始，不用开发者术语。
- 不把“无横向溢出/测试通过”当成品确认；最终由用户确认视觉与体验。

## 来源、分支与范围

- 来源：`feature/tablet-product-screens`（PR #17 仍为 Draft，含平板截图与上一版页面）。
- 目标：`develop`；沿用该功能分支追加提交，不改写历史、不另造重复素材 PR。
- 写入范围：`site/index.html`、`site/styles.css`、`site/product.js`、`site/assets/screens/`（仅删除不再使用的旧小裁图）、`scripts/test_product_pages.py`、本规划。不涉及 Android、BLE、协议、设备、GitHub 保护与部署工作流。
- 视觉：白底 + 近黑文字 + 中性灰分区；系统字体；大字号中文标题；主 CTA 为黑色胶囊；截图圆角卡片、细描边与柔和阴影；手机端同样显示完整截图，不裁切、不全出血。无外部字体、无生成图、无第三方运行时。

## 页面结构

1. 极简导航（功能 / 兼容设备 / 下载 / GitHub）。
2. 首屏：主标题「更懂你的 / HOYI app」+ 一句说明 + 下载/了解功能 CTA + 完整首页截图（桌面与手机都显示完整画面，手机保留圆角卡片边框并提示可点开放大）。
3. 概览数字（100 条工厂曲线 / 8 款电子秤型号 / 30 天本机记录）。
4. 两个功能段：实时萃取曲线、历史回看；均为“短文案 + 完整截图卡片”，手机端同样完整显示，不裁切。
5. 能做什么：六条能力（连接、曲线、观察、调整机器、回看导出、导入旧数据）。
6. 兼容：手机/平板、固件 1.1.3、电子秤三行；8 款型号表收进折叠块。
7. 下载：版本、大小、下载按钮、**3 条关键提示**；安装包详情与完整风险声明折叠。
8. 三步开始、常见问题（4 条折叠）、页脚。

## 用户第二次反馈（2026-11-06）：手机上图片显示不全

- 反馈：桌面观感可以，手机上图片显示不全。原因是手机端使用了同一原图的连续局部裁图，用户读成“图片被截断”。
- 处理：取消手机端 art direction 裁图，桌面与手机都显示完整截图；手机保留 20px 边距、圆角、描边与阴影作为“完整截图卡片”，并在图注加“点击放大”。删除不再使用的 3 张 `*-detail.png`，`provenance.json` 升到 schema 3（原图 + 去系统栏展示图），测试改为断言“完整截图”和原图可打开。
- 取舍：手机端截图整体变小、细节需点开灯箱放大查看；换来“完整可见”。仍未做图片格式优化（WebP/多倍图），页面截图合计约 1.4 MB，列为后续可选项。

## 用户第三次反馈（2026-11-06）：文案与主场景

- 反馈：首屏“把咖啡机装进手机里”偏土，且主要使用场景是平板，不是手机。
