# 完杯后在 HOYI.AI 里评价本杯

- 来源：`develop@7aa03acd`；工作分支 `fix/completion-open-ai-chat`，PR 目标 `develop`。集成按[仓库 Git 工作流](../git-workflow.md)。
- 用户操作：在完杯卡点「AI 评价」，进入平时的 HOYI.AI。应用代发一条自然语言提问，无须再点发送；回复留在当前模型的对话里，可以继续追问。已有草稿和待发附件不属于这次提问。
- 实现：保留完杯与已保存采样的同杯绑定，替换单杯报告目的页。使用普通聊天的同意、模型、思考和消息流程；本杯记录随问题传给聊天，不用「最近一杯」代替。不改变后台自动评价或其默认关闭设置。若之前从聊天推荐卡进入萃取页，则返回已有聊天实例，避免旧聊天覆盖新消息。
- 验证：覆盖已写草稿、同杯绑定和一次性发送；用假 Key 和离线回复走真实完杯按钮到聊天的路径。首次同意和旋转不能造成重复发送。区分本地 JVM、测试 APK 编译和 Android 实际运行结果。
- 设备与回退：不改 BLE、采样格式或机器操作，不使用用户 Key，不安装用户平板，不手动发版或修改版本、签名。聊天存储保留旧格式读取能力；如需回退入口，保留已写入的新会话格式读取能力，不清聊天、历史或其他用户数据。
