# 固件版本与协议支持状态

首页咖啡机卡片新增只读版本状态，补齐旧版版本查看的日常入口。本次不新增更新、探测或控制命令。

`DeviceSession.observedFirmware` 从通过当前连接认证阶段后接收的有效 `0x83` 设置字段构造不可变 `CoffeeFirmware`。未认证帧、错端点、旧连接帧不能提供身份；断开、失败或换设备清除原设置，版本随之清空。Hub 和 Mobile 只透传版本身份，不把未知固件设置送入正常控制快照。

| 状态 | 首页展示 |
|---|---|
| READY、已验证的 1.1.3 协议配置 | 固件 1.1.3 · 已验证协议 |
| UNSUPPORTED，例如 1.1.4 | 固件 1.1.4 · 未验证，控制已禁用 |
| 未认证、重连、断开、失败或未读取版本 | 固件版本：等待连接后读取 |
| Mock 已就绪 | 模拟固件 1.1.3 · 无蓝牙控制 |

“已验证协议”表示匹配当前已有报文证明和固件许可；不表示所有功能已验收，也不保证机器执行结果。显示版本不产生新控制许可。未验证固件仍不接受启动、停止、设置、立即睡眠、预热或杯数重置。

离线会话测试检查认证前版本为空、1.1.3/1.1.4版本值、断开与换设备清除、旧连接通知被忽略，以及未验证固件控制请求没有新增传输调用。三个 UI 单测检查就绪、未验证、断开/连接中与 Mock 文案；真实版本显示和小屏布局仍待设备验收，云端 Mock 采集仅验证模拟界面。
