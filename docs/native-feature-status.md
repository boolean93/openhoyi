# 原生版功能边界与下一步

此表以当前代码和旧版 `hoyi-project/docs/features.md` 为准；“已编码”不等于已在 Alpha 上实机验收。用户要求暂不安装、操作平板，安装时间由用户另行通知。

| 功能 | 当前状态 | 继续推进所需证据 |
|---|---|---|
| HOYI 连接、认证、实时遥测 | Lab 已在固件 1.1.3 实测；Alpha 共用协议与会话层，页面和前台服务已编码 | Alpha 独立包的权限、连接、前后台和断线实测 |
| BOOKOO 连接、前台 10 分钟自动重连、独立去皮 | Lab 双连和记忆秤连接有短时证据；Alpha 自动拉起服务、重试及去皮已编码 | Alpha 冷启动重连、重复选择、去皮后归零与负重量实测 |
| 100 条工厂曲线、五个槽位、萃取启停 | 旧版编码器生成的两种秤模式报文逐字节匹配；启动门禁、结果未知、安全提醒已编码 | 人工监护下按顺序验证停止、去皮、三条采集曲线，再验证工厂槽位；记录机器实际动作和最终杯重 |
| 机器设置、每日睡眠计划、立即睡眠、杯数重置 | 已编码旧版报文与回读确认，不自动重发未知结果 | 每类设置至少一次新鲜回读和失败路径实测；高风险操作单独安排 |
| 实时曲线、本机历史、ZIP 导出 | 压力、机器水流、温度、秤重和秤报告流速已接入；旧采样 v1 可读；机器手动萃取的被动识别与历史已编码 | 小屏图表、文件选择器、过程退出与部分曲线实测；手动拨杆真实帧验证识别阈值，秤流速物理单位校准 |
| 深浅色与原生 UI | 六个页面共用昼夜资源，首页 Switch 保存偏好 | 两种模式下的页面对比度、系统栏、重建后的 BLE 连接实测 |
| 旧版自定义曲线与曲线编辑 | 尚未接入，用户已明确后置编辑 | 取得旧包 `hy_chartLib` 的实际导出数据；任意自定义曲线须有逐字节报文验证和参数范围审查 |
| 旧版萃取历史迁移 | 尚未接入 | 取得旧包 `brew_history_v1` 的实际导出数据并确认数据许可；旧记录是 `points.{t,press,flow,wFlow,wTrend}`，不含原生采样的全部机器字段，须保留来源及缺失值，不能伪装成 Alpha 完成的萃取 |
| 其它秤型号 | 当前仅实现 BOOKOO | 对每个型号分别取得真实通知、初始化、去皮和负重量样本；不复用 BOOKOO 写入 |
| 维护、排水、校准、恢复出厂、OTA | 不开放 | 需对应机型、固件和实机协议序列；对于缺少可靠回读的命令，需要单独设计中断与人工恢复流程 |

旧版“压力上限 10/12 bar”开关是 App 本地曲线编辑与图表范围偏好，不向机器写入；待曲线编辑阶段再实现。旧版水箱滤芯 `0x18` 有写入命令，但当前已验证的固件 1.1.3 未提供代码可确认的回读位，暂不开放写入。现阶段不把编译或日志里的 GATT success 当作机器执行成功。

完成当前用户自用范围的主要阻碍是 Alpha 实机验收。用户安排安装前，仍可继续做协议只读分析与离线测试；不能声称硬件等效或发布完成。
