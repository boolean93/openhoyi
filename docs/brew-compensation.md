# 冲泡温差补偿

旧版 `brewTempDelta.vue` 使用 `0–5 °C`、步长 `1 °C` 的选择器。保存时调用 `setBlewTemp(10 × 摄氏度)`，发送 `05 02 00 <十分之一度> 00`；机器 `0x83` 设置帧的字节5以十分之一度回报。旧版显示冲泡温度时，将这项补偿从机器原始温度读数中减去。

原生版只开放旧界面的六个值。写入前要求已验证固件、当前连接设置帧、新鲜且已唤醒的待机遥测，并排除萃取、预热和其它设置事务。写入成功只证明蓝牙传输，后续新的 `0x83` 设置帧回报对应十分之一度值才显示已确认。工作室模式预热判断使用最新回报的补偿值。

`generate_machine_setting_oracle.py` 已加入旧版 `setBlewTemp` 的六条帧；机器设置对照总数为593条。当前没有 Alpha 实机设置写入和温度对照证据。
