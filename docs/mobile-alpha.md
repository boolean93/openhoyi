# OpenHOYI Alpha 第一段功能

包名 `io.openhoyi.mobile`；独立于 `io.openhoyi.lab` 诊断包和旧 HOYI。没有 UniApp、JS 或 WebView。`HomeActivity` 只负责权限、扫描选择和展示，`MobileService` 持有 `NativeDeviceHub` 及双 BLE 连接，曲线页从 `CurveLibrary` 浏览旧版工厂元数据和已采集曲线。设备会话和编解码复用 `device-session` / `protocol-core`；两款应用通过独立的私有目录使用共享 `trace-core` 实现记录，不混用日志文件。

## 已实现

- 原生首页：启动/停止前台设备服务、扫描 HOYI/BOOKOO、输入六位咖啡机密码并连接、分别断开设备；可独立对已就绪的 BOOKOO 去皮。写入成功后还要等待新鲜的近零读数才显示“已归零”，超时显示“结果未知”；萃取期间不开放手动去皮。
- 实时状态：咖啡机温度/压力、固件号及秤重量；超过1.5秒的数据不标为实时。
- 机器设置页：展示设备返回的固件、设定温度、加热、待机、杯数和两段每周睡眠计划。可修改萃取设定温度（75–105 °C）、蒸汽设定温度（110–145 °C）、两路加热、照明及自动待机时间。旧版待机写入用 `0–4` 档位，机器回读用 `0/15/30/60/120` 分钟；设置时间时保留机器回报的待机温度，不开放修改温度。首页显示并可切换手动、自动压力、自动流量三种拨杆模式；这些设置的86条允许参数报文均与旧版编码函数逐字节对照。写入前要求已验证固件、当前连接设置帧且没有进行中的萃取；写入后必须收到新的匹配 `0x83` 设置帧才显示已确认，否则显示失败或未知。拨杆模式使用 `flags` 的 `0x80`/`0x40` 位，`0x40` 单独置位显示未知组合。运行模式位 `0x04` 涉及启动前温度等待，不在本次拨杆切换范围。逐日睡眠启用位含义未验证，不开放写入。
- 曲线库：三条来自采集记录的完整参数，以及100条旧版内置工厂曲线。可按分类浏览、查看详情、设为当前曲线；选择只保存 ID。100条工厂曲线的有秤/无秤共200条启动报文已与旧版编码函数逐字节对照；校验失败则只能浏览。三条采集曲线仍用临时编号，不声称对应旧版曲线名称。数据来源、转换和校验见[工厂曲线导入](factory-curves.md)。
- 首页五个快捷槽位：默认使用旧版前五条工厂曲线，可在曲线库将任意工厂曲线放入槽位。五槽位的1000条有秤/无秤启动帧已与旧版 `startChart` 编码函数逐字节对照；点击先进入萃取确认页。启动和停止携带相同槽位，历史记录保存槽位。槽位映射只存在本包，不修改旧版数据。
- 记忆秤：成功 Ready 后在本包保存秤地址；前台10分钟窗口由 `NativeDeviceHub` 负责自动连接。
- 页面可见性由每个 Activity 的独立 token 汇总；从首页切到萃取页或设置页不应因旧页面停止而立即关闭前台重连窗口。最后一个页面离开后等待500毫秒，避开页面切换间隙。
- 操作与传输记录：共享 `TraceStore` 有界异步写入，认证帧在传输边界脱敏；首页可通过系统文件选择器导出ZIP。Alpha与Lab各有自己的日志session。
- 萃取页：选定已验证报文的曲线后展示连接、重量、温度、压力和萃取状态。确认框展示有秤/无秤模式、最大水量和目标重量；确认后才调用共享 `ExtractionController`。服务层重复校验曲线、确认时的秤模式、固件就绪、咖啡机新鲜待机帧及秤数据时效，并记录尝试/结果/传输。手动停止为单击操作；结果未确认时阻止主动断链或停止服务，断线结果未知时可重连后显式重试停止，不自动重放启动。
- 原生萃取图：服务层从机器 `0x80` 通知记录时间、压力、水流、累计水量、温度，并在秤读数足够新鲜时附上重量；页面用 Android Canvas 实时绘制压力、水流、重量。每杯最多保留2000点，长时萃取逐级降采样，保留最新点。
- 萃取历史：仅记录 Alpha 发起的请求，保存曲线ID、开始时间、观察到的终态、停止原因及可用时的秤读数。明确观察结束后，采样点异步写入每杯独立文件，历史详情可离线绘图。结果未知会保留为未知；进程中断时的未完成记录在下一次启动标为未知，不假定成功。历史最多保留30天/500条。旧App历史不会自动迁入。

## 仍未开放

产品页尚无温差补偿、待机温度、睡眠计划等其它设备设置写入，也不开放校准或 OTA。底层控制仍受已知固件限制；工厂曲线启动需要两套旧版帧对照通过。旧版用户自定义曲线尚未导入。萃取页已经接通启动/停止代码，但尚未在Alpha上完成真实启动、去皮确认、按重量停止和异常恢复验证；独立去皮及设置写入也未实机验收。不能视为与旧App硬件等效。App进程被系统杀死时不能保证停液。

## 验证

工厂曲线100条在临时槽位有秤/无秤共200帧、五个快捷槽位共1000帧，均由只提取旧版编码函数的离线脚本生成；机器设置86帧另由旧版设置编码函数生成。资源可重复生成且字节一致。协议检查35,180项、会话检查34项、Alpha单测30项通过；debug构建成功，Lint 0错误、2条警告。当前用户要求暂不安装，新增页面尚未实机检查。
