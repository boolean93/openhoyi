# 萃取页保留机器计时

- 需求与范围：萃取顶栏与详情共用同一杯的机器秒数。新鲜待机确认结束前保持本杯最后有效读数，正常结束后保留。等待、新杯尚无证据、遥测过期或中断时不把旧值当作实时或完整时长；短冲洗结束不保留计时。
- 来源：`origin/develop` @ `95b11163`。工作分支 `fix/extraction-elapsed`，PR 目标 `develop`。
- 实现：从服务持有的 `ShotSeries` 投影已有机器计时证据，使用既有开始、结束和丢弃边界。不在页面缓存；离开或重建页面时服务仍持有本杯证据。
- 验证：单测覆盖确认结束前后、连接中断/遥测过期、等待、新杯和手动杯身份绑定。运行 `./scripts/create-pr --check-only`；普通推送后使用 `./scripts/create-pr`，等待准确头提交的 branch-policy / verify 通过再合并。
- 协议与设备：不改帧、计时单位、启停、重试、异常恢复或历史统计口径。无真实设备操作、不启动本地 AVD。
- 发布与回退：不人工发布、不改包名/签名/版本或数据格式。必要时走回退 PR，不清记录。
- 边界：仅保留当前服务实例中的展示，不从历史恢复服务退出前的读数。
