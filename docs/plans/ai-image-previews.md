# AI 本地图片缩略预览

- 范围：选择后输入区上方显示紧凑 72dp 横排预览和独立 48dp 移除入口；发送气泡内显示最大 240×180dp、FIT_CENTER 保比例图片，多图横排滚动；文件附件显示与处理不变。
- 基线：`ai-ad-compact-correction/project` 的独立目录副本；非 Git 工作树，交付相对候选的精确 patch 与文件 SHA256，不修改候选或原树。后续集成从 develop 建短分支、PR 目标 develop，遵守 [Git工作流](../git-workflow.md)。
- 改动：Presentation 只负责视图与回调；Activity 复用持久化回滚和历史引用保护的移除流程。预览通过现有 Vault 读取 v2 私有图和旧 AES 图，后台串行采样解码，临时字节 use 擦除，无新增网络/存储副本。
- 内存/生命周期：仅视口内图片加载和持有 drawable；512px 解码上限，4MiB/128项 LRU，缓存失败占位防止逐帧重试；key 包含 epoch 和完整元数据，contextGeneration/模型切换清理缓存，每次渲染旧回调失效，销毁取消并清理。
- 验证：尺寸与身份/失效/缺失缓存/文件显示 focused JVM 测试，编译与 lint；真实视觉验收由集成方后续完成，不以编译/JVM代替设备证据。
- 边界：不调用 API、不访问设备、不上传、不发布、不安装、不改版本/签名、无协议/BLE变化、不提交/推送/PR/合入。回退只撤销本次视图和加载器，不删除用户图片、凭据或历史记录。
