## 问题与推荐

现有“咖啡机睡眠 / 已唤醒”把动作与状态叠在同一按钮；秤名称/状态与独立断开按钮分离，用户不容易判断每块用途。

推荐104dp侧栏底部两个纵向设备组，取消多层描边卡。每组先是只读设备名和当前状态，下方只有一个动作区。组内归属紧密，组间8dp；不增宽主rail，不挤内容，不让状态文字承担隐形动作。电子秤专页已有导航，状态区不再重复导航；不支持/未选择时的选择动作仍进入原连接页。

- 内宽88dp；设备名14sp/20dp行高，状态14sp/20dp行高，色点只是状态的补充，不能代替文字。
- 动作区宽88dp、高至少48dp，图标20dp与14sp/20dp短动作词同排居中，8dp间距（两字动作共56dp）；长翻译自然增高换行，不缩字；完整contentDescription和tooltip说明对象、状态、动作。
- 常规设备组最低96dp（两行40+动作48+上下各4），两个组加8dp间距及分隔/外距约229dp（按首轮实现的外距/分隔精算）。长翻译/放大字自然增高，以真实测高决定移到现有顶部fallback，不能硬限高或省略重要状态。
- 设备组无独立卡片边框，动作可用轻浅底/ripple表达可点。设备区保短动作词，是本轮澄清设备状态/操作所需；曲线库新增、管理、编辑、分享、更多仍保持v25纯图标，不回退其合同。状态文字不可点，动作明确独立命中。
- 顶部fallback使用并列设备组，各组仍保相同状态→动作顺序；不修改导航方向或48dp命中。

104dp rail只有88dp内宽，无法放“咖啡机 · 已唤醒”完整14sp再加48dp按钮。左右并列两个设备组更不足48dp命中。因此不采用一行设备文字+旁置按钮，不以虚假的76dp预算压字。

## 真实状态与动作

| 设备证据 | 可见状态 | 动作与限制 |
|---|---|---|
| 咖啡机READY且新鲜Idle sleepStateRaw=0，现有全部门禁允许 | 已唤醒 | 月亮 / 睡眠；打开原确认弹窗，确认后才发送 |
| 新鲜Idle sleepStateRaw=1 | 已睡眠 | 禁用月亮 / 机身唤醒；没有App唤醒命令，不画可点太阳 |
| 掉线、无服务、遥测过期或没有睡眠字段 | 未连接或状态未确认（按真实证据区分） | 睡眠入口常驻但禁用；不推断已唤醒 |
| STARTING/RUNNING/STOP_REQUESTED或手动杯活跃 | 萃取中 | 睡眠禁用，原门禁不变 |
| sleep WRITING/WAITING_ASLEEP | 正在休眠 | 动作禁用，禁止重复发送 |
| sleep或setting UNKNOWN | 结果待确认 | 动作禁用，不自动重发或清未知 |
| 设置写入、准备或安全拦截 | 设置处理中或暂不可用 | 睡眠禁用；完整原因在可访问描述/提示，不能仅写已唤醒 |
| 秤READY | 绿点 已连接 | 断链/× + 断开；原disconnect一次入口，活动杯门禁不变 |
| 秤CONNECTING/DISCOVERING/SUBSCRIBING/INITIALIZING/SYNCHRONIZING | 中性色进度 + 连接中 | 禁用重试，避免重复连接；完整阶段可在描述中 |
| 秤DISCONNECTED/FAILED，有记住的设备 | 灰点 未连接/连接失败 | 重试图标 + 重试，调用原remembered连接路径 |
| 主动断开抑制为真 | 灰点 已断开 | 重试可显式重新连接；不标自动连接中，不后台反连 |
| 无记住的秤或权限待授予 | 未连接 | 加号/连接图标 + 连接，进入原选择/权限流程 |
| 秤UNSUPPORTED | 不支持 | 选择图标 + 选择，进入原选择页，不重连旧设备 |

状态来源约束：当前UI能直接读取DeviceState、LiveTelemetry、sleep/settings tracker、preparation、安全拦截。主动抑制已由MobileService持久化于devices/scaleAutoSuppressed，若后续显示“已断开”需只读暴露/读取真实值，不凭DISCONNECTED猜。自动恢复仍由现有service策略负责；只有真实连接阶段才能显示“连接中”，不能把默认自动连接偏好写成当前正在重连。此草案不新增服务或协议行为。

状态优先级须保守：真实活动/未知结果/写入占用优先于可操作性，连接与睡眠事实分开；实际禁用原因不能被“已唤醒”掩盖。本轮后续实施前还需将状态表与原逻辑逐项对齐，不放宽门禁。

## 替代方案与取舍

1. **推荐：两个纵向设备组，状态两行+带短词动作。** 归属明确，无需猜图标，保104dp；约229dp（按首轮实现的外距/分隔精算），高度收益有限但解决语义割裂。
2. **极简：相同分组，动作仅月亮/断链/重试图标。** 可去动作短词但48dp触区仍不能压，空间收益很小；与用户先前工具栏纯图标一致，但设备区再次依赖长按才能理解，不优先。
3. **底部仅设备状态摘要，点开统一设备面板。** 占高最小，完整解释更从容；断开/重试多一步、睡眠不再直接常驻，违背既有高频偏好，不推荐。
