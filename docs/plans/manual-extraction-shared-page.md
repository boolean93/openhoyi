# Manual observations on the real extraction route

This slice replaces the separate manual chart popup on the ordinary MainActivity shell. After two credible valve-open observations, the foreground, focused shell reveals its existing ExtractionFragment, with the prior tab/retained Fragment available via Back. The history qualification threshold remains independent. There is no automatic recipe selection, profile execution, boiler preparation/cancel, permission prompt, or App ownership of the shot. Existing extraction does not get replaced. Observe-only has no Start/Stop; follow the machine lever guidance. The chart keeps its provisional observation identity while the sample series gains its durable history identity.

A short discarded flush returns only an untouched automatic entry to its original tab or Activity. Back or explicit navigation consumes the presentation and cannot reopen the same cup. A valid completed or interrupted observation remains visible with truthful terminal state. The old Fragment class is restore-only and cannot mount a dialog.

Foreground standalone comparison/editor windows now push a non-exported PassiveExtractionHostActivity in the existing task, without task/launch flags. It hosts the exact same ExtractionFragment via a typed host and only binds to an existing service, with no creation, connection, permissions, configuration, preheat, shortcut, Start/Stop or recipe command. Modal focus defers handoff. The offered and presented lease is current observation-specific, and the scoped UI filters mismatched sample owners before render. Pressing Back resumes the original unchanged Activity; a finished observation before claim or stale restore never opens as another cup. Source validation is not a device runtime result.

Acceptance uses the actual embedded and standalone Fragment on a disposable Android Mock, on the normal application route with synthetic machine telemetry. The suite verifies provisional UI (no need to wait for history commit), short-return, exact no re-open, retained tab, modal focus/draft, comparison task return and AI editor draft. No tests send machine commands or use hardware.
