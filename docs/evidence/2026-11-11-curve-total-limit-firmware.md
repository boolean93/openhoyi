# 曲线总量上限：原厂固件独立核对

日期：2026-11-11。范围仅为曲线总量参数的解析、累计量来源和结束条件。本轮对原始二进制重新做静态反汇编；未连接设备、未安装 App、未启动 Android 模拟器、未刷写或执行咖啡机操作。

## 结论

1. **这是设备实际使用的独立累计量阈值，不只是 App 中的阶段合计。** 启动帧的 `byte3..4` 被独立写入活动配方；多个阶段的结束路径读取此值，并与流量计累计量比较。
2. **没有发现“总量必须大于等于阶段合计”的固件要求。** 解析路径没有求阶段和或用阶段和覆盖该字段。总量小于阶段合计可以使支持的压力配方在用完全部阶段分配前结束。
3. 不能把它描述为所有模式、所有阶段无条件生效的硬保护，也不能等同于杯中重量或瞬时流速。App 连接电子秤时的重量策略是另一层，见本轮 APK 证据。
4. 证据仅覆盖下面这份 1.1.4 镜像。没有 1.1.3 二进制对应证明，未验证真实流量计标定、执行延迟或停泵后的残液。

## 1. 启动帧确实配置独立总量

令 `S=0x20000760`。固件有两份 52 字节配方：持久配方 `S+0x6C`，活动配方 `S+0xA0`。接收帧起点为 `0x20000A60+0xCB`。

关键原始指令：

| 地址 | 原始字节 | 含义 |
| --- | --- | --- |
| `0x0801003E` | `90f8ce00` | 从接收缓冲偏移 `0xCE` 读 byte3 |
| `0x0801004A` | `01ea0020` | 左移 8 位，保留 16 位 |
| `0x08010052` | `90f8cf00` | 从偏移 `0xCF` 读 byte4 |
| `0x08010058` | `0843` | 合成大端 16 位整数 |
| `0x0801005E` | `02f0bff9` | 调 `0x080123E0`，无符号整数转单精度浮点 |
| `0x08010066` | `c0f8ac10` | 写入 `[S+0xAC]`，即活动配方 `R+0x0C` |

此处没有乘 0.1、没有求阶段水量之和、没有按阶段和重算总量。它与后面的各段水量字段是不同槽位。启动路径设置 `S+0x6A=1`；配方选择函数 `0x0800A2E8` 在此标记非零时返回活动配方索引 1，因此运行时读到的就是此次启动帧的配置。

## 2. 运行路径读取它决定结束

已重新解码的独立总量读取点：

| 地址范围 | 行为 |
| --- | --- |
| `0x0800E7BE–0x0800E800` | 第二段、段数不超过 2 时，从 `R+0x0C` 读总量，与累计量比较；达到后写阶段状态 9 |
| `0x0800E9A2–0x0800E9CE` | 更多阶段的第二段路径中，读相同总量阈值决定结束 |
| `0x0800EBC8–0x0800EBF6` | 第四段读相同总量阈值；不是拿第四段水量字段当结束阈值 |
| `0x0800EC1A–0x0800EC3E` | 状态 9 后的结束清理：清活动配方标志、运行状态、阶段、计数及控制输出值 |

以第四段为例：`0x0800EBD6` 的 `d168` 读取 `R+0x0C`；`0x0800EBDC` 读 `S+0x13C` 累计量；`0x0800EBE0` 调比较辅助函数 `0x08012608`；未达到时跳过结束，达到时 `0x0800EBE6` 写状态 9。

比较辅助函数对本任务的正数有限浮点输入最终执行 `cmp r1,r0`（`0x0801261C`，字节 `8142`）。调用点令 r1 为总量、r0 为累计量，随后 `bhi` 仅在“总量 > 累计量”时继续，因此达到或超过总量会进入结束路径。

固件确实使用的是独立总量，不能以“阶段水量合计”替代这个参数。尤其最后一段的分配值虽被解析保存，但上述末段结束路径用的是总量字段。

## 3. 累计量来源及限制

`0x08008B40–0x08008B7C` 递增 `S+0x27C` 脉冲计数，将其转浮点并乘常量 `0x3D3020C5`（约 0.043），保存到 `S+0x13C`。这条链是固件的流量计累计量，不是蓝牙秤发送的杯中重量。mL 是与原 App 一致的标示单位，绝对物理精度仍取决于设备标定。

`0x0800E6DE–0x0800E72C` 表明首段有条件跳过总量检查：总体 flow/chart 模式且段数至少为 2 时，该分支不检查总量。因此不能把字段包装成任何配方都绝对可靠的全局水量硬限。本轮只扩展既有支持的压力曲线参数，FLOW_RAW 不因此开放。

## 对本次实现的影响

- 复用已有“总量上限”概念，并保留各阶段水量；允许总量小于阶段合计，不能再把原生历史限制误称为固件约束。
- 新的显式压力曲线下界取 1 mL，不开放 0；上界继续使用原生既有安全范围，不把原 APK 的整个 16 位范围直接开放。上界是产品受限策略，不是此固件声明的范围。
- 保留原 App 接秤时的总量计算策略，实际下发值可能大于用户填写值，必须说明。旧数据未显式填写时保持原行为。
- 用旧 APK 独立编码对照及参数许可回归验证该扩展。静态分析与单测都不等同于真实机器停止精度验收。
