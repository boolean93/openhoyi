## 观察方式

只看 App 事件和 Android 崩溃，不循环截图，也不读取全量 logcat：

```sh
adb -s <serial> logcat -v time -s OpenHoyiMobile:I AndroidRuntime:E '*:S'
```

`OpenHoyiMobile` 的 `scale.auto_reconnect.window_open=600s` 表示前台10分钟窗口开启；`scale.auto_reconnect.attempt=N` 表示向记忆地址发起第 N 次直接 GATT 连接，**不经过 BLE 扫描**。随后应看到 `BOOKOO: CONNECTING`、初始化阶段、`BOOKOO: READY`，失败则检查 `BOOKOO: FAILED/DISCONNECTED` 与下一次尝试。`window_closed` 表示离开前台或关闭 Hub。扫描按钮另有 `scan start` / `扫描完成：N 台候选设备`。这些事件可证明 App 发起了动作，不能单独证明机器执行了写入；逐笔请求、回调和通知以 App 导出的脱敏 trace ZIP 为准。

## 顺序与通过标准

1. **Mock UI**：单独安装 Mock 包后，检查深浅色、首页、曲线库、五个槽位、实时图、历史页；操作模拟设置、睡眠计划、去皮、预热、立即睡眠，确认页面回读随操作变化。Mock 包不含 BLE 权限，结果只说明 UI 能走通。
2. **Alpha 只读连接**：确认咖啡机空闲后启动 Alpha，授权 BLE；分别连接 HOYI 和 BOOKOO，观察固件1.1.3、完整设置/睡眠回读、新鲜遥测与秤重量。无新通知超过1.5秒时读数须变成“—”。此阶段不发送萃取或设置命令。
3. **秤重连**：先确认秤曾 Ready 并保存地址，再关闭/重开 Alpha 前台窗口。观察 `window_open`、`attempt`、BOOKOO 终态；人为断链后应在窗口内按退避再次尝试。手动断开必须终止本轮自动重连。分别核对负重量、去皮写入后归零通知与5秒超时提示。
4. **安全停止优先**：有用户现场看守、机器空闲且接杯准备完成时，先检验单次已知萃取的停止入口，再测三条已采集曲线、工厂临时槽位及快捷槽位。每次记录选中曲线、目标、实际杯重、机器阀门动作、停止原因和 trace；断线结果未知时不得自动重放启动命令。不要用模拟结果代替此项。
5. **其它控制**：按逐项确认的顺序验证常用温度/加热、睡眠计划、立即睡眠和杯数重置。每次写入后必须等待新的匹配机器回读；未知结果先核对机器，不自动重试。排水、校准、恢复出厂及 OTA 不在 Alpha 控制范围。
6. **持久化与迁移**：检查实杯历史的最终/部分曲线和 ZIP 导出；再用真实旧版历史与曲线导出测试导入、条数、顺序及重复导入。个人曲线在逐条旧/新报文对照和参数审查前仍只读。

每一项记录 App 版本、设备固件、时间、结果和对应 trace 文件。任何实际机器动作与页面状态不一致时停止该项，保留数据再定位；不能用 GATT success 代替机器回读或实际动作。
