# 历史记录与两杯对比

- 范围：按已确认的横屏交互稿收紧列表、整合单杯预览，将选杯与现有两杯对比页接起来。窄屏和大字保留可达入口。
- 来源：develop / cfbf0f82；工作分支：feature/history-cup-workspace；PR 目标：develop。
- 列表：记录数随来源，不占单独横栏；保留规则点开可看。常规记录用曲线名＋到秒时间、计时＋秤读数两行；不重复日期和正常结束状态。保留异常、缺失、槽位和长期复盘信息。
- 单杯：AI 评价为主按钮，对比为次按钮。查看详情进入原有全屏页并可返回原记录；写复盘归到个人记录所在处。预览内容和操作共用完整高度，不再固定占底。保留主题、照片保护和原有 AI 数据确认。
- 选杯：同一窗口明确第一杯、候选第二杯与确认操作；当前杯可用就预填，同曲线的上一次优先，但其他长期记录仍可选。只能比较两条不同且存在的记录，不自动迁入或写入。带两个 ID 打开原有对比页；图按同一指标叠加，真实数据不足时不补值。可换第二杯并返回。
- 验证：相关单测、编译和现行脚本；用安装授权允许的设备或仓库既有设备 CI 检查列表、返回、选杯和真实绘制的布局。编译不代替界面验收。
- 推送/合并：按 [Git 工作流](../git-workflow.md) 本地检查，普通推送工作分支，使用 scripts/create-pr；必需检查通过才可合并。
- 风险与发布：仅历史读取和界面导航；不改设备协议、重试、历史格式、版本、签名或升级路径，不发版。回退用 revert PR，不卸载、不清数据。
