# BLE 应用层 v2：离线双操作验收（仅测试源码）

- 来源：`develop` 2496d5dc，阶段四本地 1dd8dc34；分支 `test/ble-v2-detached-overlap`，无推送、PR、发布或设备改动。代码完全位于 JVM 测试源码，正常 Mock、正式包和 MobileService 不可到达。
- 用现有 `DeviceSession` 和同一个 `GattQueue` 实际提交两条计划写入，再且仅在第二条成功、计划待回报时提交一条「关闭冲泡锅炉」。不是并行 GATT；不支持蒸汽、温度、全局设置或后台同步。保留两项恢复记录后才可经实际 dispatch guard；每次发前重新验证原连接及持有的记录，且仍具备测试专用有效许可、有效期限和安全环境。
- 真实解码分流，锚点取自 GATT success 回调；当前连接、当前游标下，设置确认只认具体目标位且发前不同；计划只认第二条成功之后的两段同源、按序且完整的目标。两项可以先后任意收敛，但一个不能清另一个。回报说明观察值，不证明固件事务因果。采用 6 秒离线预算，对失去许可、环境、原连接或未知结果不再发/不清未知账本；重建不自动获令牌。
- 现行 STOP 仍独立。假 GATT 验证 STOP 打断计划未完成时仍能发出且不重放后段。JVM 测试中存储模拟同步事务；不证明 Android 断电、真机支持、部署安全或降级。无 Android 运行、物理蓝牙和签名包。
- 回退：撤销测试及计划即可，不写生产仓库外部、不迁移或清除应用数据；是否、何时接入生产必须独立验证并另 review。
