# 实时萃取页快捷槽位

只为实时萃取页新增右上角「快捷槽位」，展示同一套已保存的 A–D 槽位及完整曲线名。未设置或不可用的行不能点，不跳去曲线库、不换成默认曲线；不改变首页、E（旧槽位）、拨杆或上一杯。菜单退出或页面重建都不会触发任何机器动作。

- 关闭「一键萃取」：在原页选中曲线，不启动、不发送预热命令。
- 开启：只有点选可用项这一动作可以申请一次萃取。未到温且符合当前预热条件时，复用原来的确认对话框；确认只预热，到温不自动开下一杯。其余阻止原因沿用现有提示。
- 手动或自动萃取、停止未确认、已发出的启动、秤预检、预热准备、独立秤归零或咖啡机未连接时不得换槽。操作边界在菜单打开、点击和提交时重新检查。适用的设备、曲线、设置和偏好在提交时仍须匹配。底部停止操作独立，不用进菜单。
- UI 选择仍走原路由：工厂曲线保留对应槽，草稿走槽 7，不写入咖啡机收藏；设备控制门限、驱动、协议和恢复策略均不变。

## 验收

- 单元测试：`LiveShortcutChoiceTest`，以及已有 `ShortcutStartPolicyTest`、`ShortcutStartDispatchTest`、`DirectExtractionStartTest`。
- 用隔离的 Mock 包运行 `BrewAudioInstrumentation` 参数 `liveShortcutChecks=true`，覆盖行配置、旧绑定失效、偏好关闭、D 对应曲线、第二次点击不换槽、可停止且不再自动开始。
- 视觉矩阵：320/360dp 手机及 1.3× 字号，横/竖平板和分屏；核实长曲线名可完整换行、标题控件可点、萃取时菜单关闭、停止按钮在视口内。用独立 Mock 验证温度提示的取消与确认，以及预热完成后不发起萃取。勿用正式包或连接真机。
