# 曲线库、历史预览和照片缩略图

- 从 `develop@39af7326` 建立 `fix/library-history-photo`，目标为 `develop`。按[项目工作流](../git-workflow.md)做本地检查，分享改动时推送工作分支并通过 `./scripts/create-pr` 创建 PR。
- 曲线库列表每个有效阶段画一根柱。压力柱用雾蓝，流量柱用灰青，两类柱各自使用共享量程，横向对比同类阶段。首页快捷曲线沿用现有图形。
- 历史页宽屏初次打开时预览当前来源的最新记录，有已选记录时优先恢复。窄屏以列表为入口，自动预览只读。
- 外观设置用已加载的照片绘制预览，选中标记在深浅主题下均可辨。无可用图片时仍保留设置入口。
- 验证列表阶段辨识度、宽窄历史与切换来源、照片显示及纯色回退。用有纹理的壁纸和纯色背景对照截图。
- 仅涉及展示与本地页面选择，不发版。沿用既有签名、数据和设备协议。回退本次代码即可恢复原界面。
