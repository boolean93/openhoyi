# 设置锚点设计规范：用户选定 A

状态：用户已选左侧纵向二级目录 A，允许按此实现。参考图为本任务 `settings-design/A-left-index.png`。旧 v37 的有限首屏视觉通过及旧的独立设备页方案均不代表最终设计。本文与 `2026-10-31-settings-inventory.md` 一起使用；清单描述已有行为，本文覆盖其中已过时的页面归属。不得因改版删减原功能。

## 已确定的结构与视觉

- 保留既有最左主导航、青绿/白色配色、按钮样式和状态区域；不引入棕色、全新暗色主题或新主导航。现有用户深色模式仍需适配。
- 设置内部采用 A：顶部“设置”，左侧从属文字目录，右侧一份连续滚动文档。目录不是页面切换器；点击仅定位锚点。
- 目录顺序与章节标题完全一致：设备连接、机器参数、待机与计划、电子秤、外观与语言、萃取反馈、维护与诊断、关于。“机器功能”可为机器参数内的小标题，不另设不匹配的目录项。
- 设备连接直接内联。咖啡机/秤身份、连接状态、更换/分别断开、扫描、候选列表与错误都在该章节。更换定位并展开对应角色候选；不先断开，不自动扫描或连接。扫描由明确点击触发。
- 非必要不设二级页面。常规参数、能力说明、关于、导出都原位可达；六位密码、危险操作确认、每周每日复杂时段编辑可保留适当弹窗。称重工具仍是有来源返回的工具目的地。
- A 是布局参考，不是文字/数据/尺寸规范。图中的 HOYI/BOOKOO/已连接不得作为默认真实状态；以实际快照及资源文案为准。

## 完整功能归属

详尽范围、数值校验和保存协议见来源清单，至少保留以下项目。

| 锚点 | 内容与必要补全 |
|---|---|
| 设备连接 | 当前机器/秤状态与身份、明确标注已记地址、扫描/扫描状态、按角色识别候选、协议/只读能力、连接/更换/各自断开、认证密码、权限/蓝牙/定位及错误、原有停止设备服务操作（如仍为支持功能，放章节尾部并保留忙碌门禁） |
| 机器参数 | 三项温度、加热两项、照明、供水方式、运行模式；**拨杆模式选择（手动/压力/流量）及当前状态必须可达**，复用原 HomeFragment 的能力/新鲜度门禁、确认和 Mock 限制，不能只留在已失去入口的旧 deviceCard |
| 待机与计划 | 自动待机时长、待机温度、每周计划总开关、七天启用/睡眠/唤醒编辑及回读；立即休眠保留主导航快捷操作，章节可有原位操作行，禁止丢失现有状态/未知结果 |
| 电子秤 | 0.1g 本地精度、实际能力、只读说明、使用帮助、称重工具入口；去皮/本地计时等继续在称重工具，不伪造新的设备能力 |
| 外观与语言 | 深色主题、八种既有语言、失败回退、重建及通知刷新 |
| 萃取反馈 | 本地完成提示启用、试听/停止、保存失败、离页停音；不新增不存在的音量/触感控件 |
| 维护与诊断 | 累计杯数及原有严格清零流程、详细回读、诊断ZIP导出及结果；固件/告警等原主页详情信息需有可见归属，不因替换更换弹窗丢失 |
| 关于 | 名称、版本名/码、运行模式、包名 |

预热、萃取、重量/流速显示等仍由相应主页面/工具承载，不塞入设备连接。交付前对旧 HomeFragment deviceCard 每个控件逐项记录新归属或仍可达入口，尤其拨杆、休眠、固件/告警和停止服务。

## 行、状态与响应规范

- 基于窗口可用宽度而非设备类型。宽屏索引约152dp，正文间距24dp；至少保留正文约560dp才并排，最终阈值以真实长文本测量决定。窄屏索引变48dp紧凑分类选择器，正文单栏。
- 使用现有 View 技术栈，不为此迁移 Compose。每章一组平铺行、细分隔线，避免卡中卡。普通行56–64dp，有说明约72dp；所有交互触控区至少48dp，字体沿用现有 tokens。
- 标签/辅助说明在左，值/单位/提交在右，三项温度列对齐；宽度不足整行自然换为两行，不裁切输入、按钮和单位，不横向滚动正文。
- 本地偏好可直接开关；机器操作继续确认、门禁、原回读判定。设备写入中/待回读/失败/未知清晰可见；未知不得自动重试/清除。章节离屏时目录显示简短状态标记，不能只靠颜色。
- 不再强求全部常用设置挤进第一屏。A 首屏重点是连接管理和温度，后续配置通过目录和滚动自然到达。

## 锚点、草稿和返回

- 点击索引滚动至章节标题，扣除实际固定栏高度及8–16dp余量；标题不得被遮挡。滚动同步高亮当前章节，底部短章节也可选中。程序滚动期间防止选中状态抖动；用户打断后恢复跟随。
- 保存稳定章节ID、相对滚动偏移、草稿和展开状态；旋转/主题/语言重建恢复。点击锚点、折叠、切分类不提交、不重建表单、不增加返回栈。
- 原始回读不覆盖正在编辑的草稿。离开控制器关闭所属弹窗、释放观察与试听，不能创建第二BLE owner。连接扫描和异步回调遵守宿主可见性。
- 返回先IME/弹窗，再当前详情/萃取覆盖页，再有来源工具返回；设置内锚点不消耗back。旧设备页入口若保留只路由至设置设备锚点，不叠加多层页面或循环。
- 章节标题使用accessibility heading，索引有选中语义；TalkBack/键盘顺序为主导航、设置目录、正文，隐藏目录不得仍可聚焦。锚点点击后可将无障碍焦点移至标题，手动滚动不抢焦点。保留RTL、长语言、大字体与48dp目标。

## 验收与边界

1. 与A核对既有视觉和层级，设备操作确实内联；无无意义独立页、大入口或嵌套卡片。
2. 清单每项及旧deviceCard项目均可达，尤其拨杆模式；行为不得因重新排版被重写或弱化。
3. 宽/窄窗口、大字体、RTL实际检查；索引跳转、滚动当前项、固定栏遮挡、底部短章、旋转恢复均有运行证据。
4. 草稿、保存失败、待回读/未知、权限拒绝、连接错误、密码校验、返回层级专项验证。Mock不等于设备连接/写入验收。
5. 原视觉测试需迁移到真实新锚点/控件，不以编译通过代替运行通过，不删除门禁伪造成功。
6. A图独立审查结论：符合用户选定的原视觉、从属左目录、连接内联及单列设置行方向，可作为实现参考；不证明实际代码和设备行为验收。
