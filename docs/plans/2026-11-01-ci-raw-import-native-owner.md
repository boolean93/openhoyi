# Raw import restoration and native IME ownership

Observed on exact PR head 4ff3e91: M3's strict recreation assertion reached the full raw editor case and failed only because scrollY changed 4885→4270 after native IME hide expanded the viewport. Product evidence had applied 4885 while IME was visible. Text, focus and selection were preserved. This is a real restoration race, not a retired UI expectation.

Keep the original exact raw text/focus/selection/nonzero scroll and strict native IME requirements. Move the animation observer from the reparented form host to the stable window decor. A weak root→opaque-token ownership map prevents obsolete sessions from continuing or clearing a successor's callback. Progress replaces the current native running-animation set, including animations whose prepare/start was missed.

A candidate includes actual root/editor/window-token identities, native IME visibility/insets, editor/layout and viewport sizes. Observe it across real draw/pre-draw boundaries without pending layouts/animations before issuing the single native show request and again after its native result before committing scroll. Any observed identity/inset/layout/animation change resets the candidate. These observations are not a guarantee against arbitrary future system hides. There is no timer, repeated show, hidden-IME retry, larger timeout, altered scroll expectation or synthetic IME acceptance.

User touch, pre-IME Back and normal Back cancel pending restoration before delegating unchanged event behavior. A changed raw value also cancels, while framework restoration of the identical saved text does not. The shared beanInput helper only accepts an optional editor factory; all other callers retain the original EditText construction and styling. The Import-specific editor observes pre-IME Back without consuming it. Listener, lifecycle observer and callback cleanup remain scoped to the owning session. Draw invalidations are finite candidate observations; an unresolved input-method result cannot create a continuous render loop. Saved-hidden IME restoration does not require an active IME connection.

Validation: the production-used RawImportRestoreReadiness state gate has six JVM regressions covering draw/candidate changes, progress without prepare, native result reset, user cancellation/owner replacement, finite draw requests without a result, and saved-hidden IME connection requirements. Final targeted JVM tests pass (6 tests, zero failures/errors); assembleMockAndroidTest and the targeted test task complete successfully in 1m22s (80 tasks). IME diagnostic schema checks pass 14 counterexamples plus one lifecycle counterexample; these are offline checks, not Android callback execution. Independent code review covered the actual production helper and its callers. Original strict M3 runtime checks remain unchanged and must pass in the new CI run; native animation/user Back cases are not claimed as runtime-passed by compilation. The existing broad curve-visual selector installs disposable fixtures and is not a safe standalone raw-only selector on a user's tablet. Installer may manually exercise a raw draft/recreation using its preserved Mock fixture, without decoding/importing/saving a curve or touching Debug data.
