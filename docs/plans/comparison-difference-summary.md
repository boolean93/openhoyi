# 双杯差异摘要

- 需求与范围：双杯对比的可滚动详情中简短说明压力、注水量、温度、出杯净重哪杯更高、差多少；相同或缺证同样明确，不改图表、选杯或原有记录表。
- 来源分支／基线：`origin/develop`，`e27a7b06`。工作分支 `fix/comparison-summary`，PR 目标 `develop`。
- 统计口径：已结束记录的观测萃取样本，压力取峰值，温度取采样中位数；注水取末次记录的机器累计量，回退则不比较；净重取末次记录的已确认单一坐标读数，不用原始秤值或估算值。末次记录不等于最终出杯。缺一项不影响其余；按显示精度判断相同。
- 实施：将纯统计和页面资源分开；复用异步样本加载与选杯身份、主题和应用字号；摘要滚动查看，不改变主图空间预算。
- 推送与合并：本地门禁通过后普通推送，使用 `./scripts/create-pr`；等待精确头提交的 `branch-policy`、`verify`。不直接推目标分支。
- 验证：JVM 单测覆盖差值、相同、换杯、缺证、断段；Mock 页面测试覆盖实际控件和滚动可达性。先跑本地完整非 AVD verify 并编译页面测试。真实窗口验证仅用现有隔离云端入口，不在 Mac 上启动 AVD。
- 协议／设备风险：只读已有记录；不改协议、单位编码、硬件命令、门禁、重试、未知记录或存储。
- 发布与回退：不发版、不改签名和版本、不安装、不操作设备；必要时通过 revert PR 回退，保留所有记录。
- 未完成与阻塞：实际运行与编译分开记证；Mock 不作为真实萃取或硬件证据。
