# 原生版 UI / UX 设计

## 目标与证据

原生 Alpha 已能完成连接、选曲线、萃取、停止、设置回读和历史记录，但旧界面把状态、主操作和低频维护操作排在同一条长列表。用户需要频繁滚动，难以一眼判断是否可以开始，也难以在萃取中迅速找到停止入口。

设计优先级是：**先看机器和秤是否就绪 → 选定曲线 → 明确开始 → 萃取中持续看数并随时停止 → 事后查看记录**。机器设置保留完整功能，但与冲煮主路径分开。

## 页面规划

| 页面 | 首屏重点 | 次级操作 | 安全与状态 |
| --- | --- | --- | --- |
| 首页 | 双设备连接、四项机器实时值、当前曲线、开始萃取 | 五个快捷曲线、去皮、拨杆模式、睡眠、导出、停止服务 | 设备故障和机器告警在主操作之前显示；只有新鲜遥测才显示数值 |
| 曲线库 | 搜索、类别、可触控的曲线列表、分段目标示意和所选详情 | 使用曲线、放入快捷槽位、浏览旧版导入曲线 | 只读或未校验曲线明确不可萃取，选择本身不发送 BLE；示意图不冒充实时曲线 |
| 实时萃取 | 就绪条件、时间/压力/秤重/流速、曲线图 | 预热、取消预热 | 开始需原有二次确认；运行时固定显示“立即停止”；结果未知原样提示 |
| 机器设置 | 连接与机器回读状态、常用设置 | 睡眠计划、累计杯数重置 | 写入后继续等机器回读；不可编辑条件沿用服务层判断 |
| 历史 | 记录时间、状态、曲线、详情 | 导出、旧版导入与浏览 | “结果未知”与“已观察结束”保持区分 |
| 历史详情 | 结果、时间、停止原因、采样曲线 | 返回历史 | 仅展示本机采样；秤重保留“未经杯重校准”说明 |
| 旧版浏览页 | 导入内容和来源 | 导入、查看详情 | 明确只读；旧数据不参与机器控制 |

## 交互与视觉规则

- 原生 View 组成界面。共享 `HoyiUi` 负责标题、卡片、按钮和底部导航，业务状态仍在对应 Activity 与 MobileService 中。
- 主操作使用蓝色 54 dp 高按钮；危险停止操作固定在萃取页底部操作区。其他按钮至少 48 dp 高。
- 浅色为暖白底与白卡片，深色为海军蓝黑底与深灰卡片；两套主题共用布局和文字结构。
- 横屏平板中首页、曲线库和机器设置采用双栏；窄屏首页先显示当前曲线和实时值，再显示低频机器控制。窄屏曲线库从列表进入详情，详情可返回列表。底部导航固定，页面内容使用剩余空间。
- 首页设备控制和设置页每周计划编辑默认收起；展开仅改变界面，不发送蓝牙命令。
- 设备值只在现有 `LiveTelemetry` 判定有效时呈现；断链或陈旧数据使用“—”，不沿用旧读数。
- 首页复用旧版应用自带的 HOYI 机器透明图作为装饰，不表达设备就绪；连接状态由独立状态点及实时数据呈现。
- Mock 版本保留独立包名与原有安全提示，不连接 BLE。

## 实施边界与验收

本轮只改移动端原生 UI 代码与配色资源。没有改协议、连接、曲线编码、设置写入、开始与停止条件，也没有改历史存储。

验收需要 Debug / Mock 编译及单元测试通过；设备可用时再检查深浅色、横竖屏、候选设备列表、曲线筛选和运行中固定停止按钮。设计稿不是运行截图，不能替代真机视觉验收。
