# 七语言 Android 资源转换

## 实现范围

完整catalog保留每语言872键，生成器排除app_name，每份正式XML871键、七份6,097条。默认中文XML、Mock品牌覆盖、catalog源值和生产Kotlin/控制模块未改；Alpha名称OpenHOYI Alpha，Mock名称HOYI Mock。

android_resources.py先核对源SHA/内容，再校验七语言全部键、格式、空值/换行/控制字符；全部通过后才生成。输出按键排序、UTF-8 XML、外层Android引号及反斜杠/单双引号/换行/制表/CR/@?转义，保留参数、空格和XML字符。--check只比较预期字节，不创建目录、不写文件；没有漂移则生成也不重写。写盘错误不保证七文件原子性，后续一致性检查必须通过。

verify_apk_resources.py先验证catalog，实际编译/链接六组转义fixture并回读，再解析Alpha/Mock AAPT2 dump逐键逐配置比较。默认中文和七语言全部全文必须匹配，资源键/配置缺失或多余、任何语言覆盖app_name均失败；两个APK各6,969值。源JSON检查不替代此编译验证。

LanguageDraftTest旧临时禁止语言XML断言在新增资源后真实失败，已改为完整catalog键与871条/无品牌覆盖检查。原分组来源检查保留；Gradle Test新增values-*/strings.xml输入，CI新增生成--check和APK检查，不自动生成缺失资源。

## 证据与边界

转换测试最初因缺转换模块失败，完成后通过。实际APK比较发现legacy_curve_detail双换行被dump读取器遗漏（默认中文与新语言都出现），添加真实无缩进空行+最终输出换行测试先失败，再修复读取器；随后全部值匹配，没有改变默认/译文来掩盖读取错误。19项Python测试均通过；六组转义每次CLI由真实SDK35 AAPT2编译/链接检查。

完整离线协议39,823检查/32,856条通知回放、会话92场景、共享JUnit69项；Alpha/Mock各133项（132通过、1缺真实旧导出跳过），三个构建成功。最后登记Test输入后的回归成功，APK任务UP-TO-DATE，随后再次核对实际APK的编译值。独立两轮只读审查未发现实质问题，没有声称本次云端CI已绿。

本阶段没有语言选择调用方，默认简中；显示的原曲线名字/tips、用户数据与规范历史原因不直接翻译成控制数据。Android资源选择/初始化/配置缓存与Activity重建、停止入口可达、RTL/长文字及母语语义仍需运行时和视觉证据；无真机操作。语言编译通过不证明硬件安全，也不表示全部功能对标已完成。
